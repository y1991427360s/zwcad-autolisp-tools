# ZW-auto_lisp

面向中望 CAD 2026 的 AutoLISP 常用命令集合，主程序为 `AA整合版本.lsp`。

## 使用

远程开发入口：双击 `develop-on-sen3.cmd` 在 sen3 上使用 Codex；完成提交和推送后，双击 `update-from-sen3.cmd` 更新 Windows。详见 [服务器开发说明](docs/服务器开发.md)。

1. 在 CAD 中运行 `APPLOAD`。
2. 加载 `E:\366256\ZW-auto_lisp\AA整合版本.lsp`（或将其加入 APPLOAD 启动组，实现每次启动自动加载）。
3. 输入所需命令。完整清单见 [`命令索引.md`](命令索引.md)。

## ZTF 字体搜索器

输入 `ZTF` 可搜索并修改文字样式字体。左侧可搜索文字样式，右侧可搜索 TrueType/TTC/OTF 和 SHX 字体；选中后点击 `Apply to Style`，会更新该样式下的文字。`txt.shx` 等 SHX 字体由 ZWCAD 支持文件搜索路径查找。

常用文字命令：

- `HZBG`：框选文字一键生成表格，行高和行中心间距均为 5，按各列最宽文字自动列宽、左右各留 3。详见 [HZBG 说明](docs/HZBG.md)。
- `T`：将所选 `TEXT/MTEXT` 刷为 `HZ` 样式，高度 `3`、宽度比例 `0.7`；`MTEXT` 会先拆成 `TEXT`。
- `T2`：将所选文字刷为 `HZ` 样式、宽度比例 `0.7`，高度 `3` 若与周围对象间距不足 `0.3` 则自动降低到可用的最大值，并保持文字中心位置。
- `QSTXT`：从选择内容中保留文字对象。
- `QR`：修改文字高度。
- `QW`：提取选中文字，按行排序后用顿号连接并写入剪贴板。
- `QR2`：连续选择文字并逐轮输入高度进行修改，按 `Esc` 退出。
- `DEA`：删除所选对象中高度小于 `0.1` 的 `TEXT/MTEXT` 文字。
- `WI`：修改文字宽度比例。
- `HBBG`：框选多张完整直线表格，按图纸位置从上到下复制拼成长表（同上沿高度时从左到右），不按标题排序。指定长表左上角即可输出；保留各段标题、原列顺序、文字样式及原表，接缝重复边线只留一条，一次 `U` 可撤销。详见 [使用说明](docs/HBBG.md)。
- `ZDWI`：按各列最宽文字调整表格列宽，文字左右各留 3 个图纸单位；预选整行横线即可自动收集表格。支持直线及闭合多段线边框，外框、分隔线与文字可位于不同图层。
- `SSS`：先交叉框选表格上方需要拉伸的对象，再输入命令，按选区下沿所在行调整高度。输入大于 0 的目标行高度，支持小数，回车默认 10；零和负数会要求重新输入。使用水平世界坐标系，一次 `U` 整体撤销。 横线识别允许端点 Y 偏差不超过 0.01 图形单位且坡度不超过 0.0001；近重合横线（高差不超过 0.01）不作为一行的上下边。仍需选区下沿附近存在真实的上下横线。
- `ZUO` / `ZHONG` / `YOU`：先将所选 `TEXT/MTEXT` 的完整对正方式统一为左中、中中或右中，再执行对应的水平对齐。
- `SHANG` / `XIA`：先将所选 `TEXT/MTEXT` 的完整对正方式统一为中上或中下，再执行对应的垂直对齐。
- `MJ`：框选单列表格的全部边线和文字，自动按最长文字收窄表格宽度并将各行文字居中；保持表格总高度和各行高度不变。
- `ZJ`：选择两条水平直线，在各自左端生成长度 10 的短线，并在左侧生成宽 12、高度至少 20 的矩形；生成的连接线与矩形固定为青色。`YJ` 为右端对称命令，颜色规则相同。
- `KMZ` / `KMY`：选择两条水平直线，在各自左端（KMZ）或右端（KMY）生成长度 15 的连接短线并在外侧生成自适应宽度（文字两侧各留 2.5mm 间距）、高度至少 20 的矩形；在两条短线上方 1.5mm 分别居中标注“+KM”和“-KM”，在矩形正中心居中标注“直流馈线柜”。线型均为 HIDDEN2，颜色统一固定为青色。
- `LNZ` / `LNY`：与 KMZ/KMY 对称同构，分别向左（LNZ）或向右（LNY）生成连接短线与矩形；两条短线上方 1.5mm 分别标注“L”与“N”，矩形正中心居中标注“相邻屏柜”。矩形宽度随文字自适应（文字两侧各留 2.5mm 间距），线型均为 HIDDEN2，颜色统一固定为青色。
- `UPSZ` / `UPSY`：与 LNZ/LNY 对称同构，分别向左（UPSZ）或向右（UPSY）生成连接短线与矩形；两条短线上方 1.5mm 分别标注“L”与“N”，矩形正中心居中标注“UPS电源柜”。矩形宽度随文字自适应（文字两侧各留 2.5mm 间距），线型均为 HIDDEN2，颜色统一固定为青色。
- `BZ` / `BY`：与 KMZ/KMY 对称同构，分别向左（BZ）或向右（BY）生成连接短线与矩形；两条短线上方 1.5mm 分别标注“B+”与“B-”，矩形正中心居中标注“同步时钟主机柜”。矩形宽度随文字自适应（文字两侧各留 2.5mm 间距），线型均为 HIDDEN2，颜色统一固定为青色。
- `YDZ` / `YDY`：支持选择两条或两条以上多条水平线，分别向左（YDZ）或向右（YDY）生成长度 20 的连接短线与矩形；短线上方文字从上往下依次标注“701”、“-901”、“-903”、“-905”...，矩形正中心居中标注“公用测控柜”。矩形宽度随文字自适应（文字两侧各留 2.5mm 间距），线型均为 HIDDEN2，颜色统一固定为青色。
- `AAE`：选择块内属性文字，在自定义窗口中编辑并按回车直接保存；支持通过 CUI 绑定双击动作替换原生增强属性编辑。详见 [AAE 设置说明](docs/AAE.md)。
- `XYG`：一键框选图纸区域，自动识别绿色水平线统计芯数并横向排列原理号，提取左侧大字分类与电缆信息，生成自然排序的电缆清册汇总表格。详见 [XYG 说明](docs/XYG.md)。
- `HBDL`：框选电缆清册表格文字，就地修改主电缆芯数（如3改4）并在原理号末尾向后堆积追加，消除并入行；无需新建表格。详见 [HBDL 说明](docs/HBDL.md)。

## CC 复制并替换副本文字

先将新文字复制到 Windows 剪贴板，在 CAD 中预选一个文字对象，输入 `CC`，指定第一个点（基点）。随后移动鼠标即可看到替换为剪贴板文字的副本拖动预览，支持连续多次点击放置；每次点击生成一个副本并继续拖动下一个，按回车、空格或 Esc 结束退出。原对象和剪贴板不变。操作前需启用预选（`PICKFIRST=1`）。

支持单个 `TEXT`、`MTEXT` 或 `ATTDEF`。完整替换不沿用 `QE` 的“至”字前缀保留规则。指定基点后创建并替换副本，再由原生 `MOVE` 提供文字拖动预览和对象捕捉；退出或 Esc 取消时删除未确认的副本，并恢复预览设置。一次 `U` 整组撤销。实现、异常清理和验证边界见 [CC 使用与验证说明](docs/CC.md)。

## FDX 连续分配文字

先选中目标方框，运行 `FDX`，选择按行或按列排序。随后每批选择 `TEXT/MTEXT`，按空格确认，命令自动把文字移入当前方框并按 `DX` 规则排列，然后进入下一框，无需再次输入 `DX`。按 `Esc` 或空选回车结束。

支持闭合矩形多段线和完整直线框。锁层、移动失败或 DX 排列空间不足时，本批不前进；已移动的本批文字会尝试恢复原位。本轮修改使用一个撤销组。详细排序、颜色规则和验证边界见 [FDX 使用说明](docs/FDX.md)。

## 主要文件

- `AA整合版本.lsp`：主整合程序（自包含全部命令，直接加载即可）。
- `AAE.dcl`：快速属性编辑对话框界面定义。
- `ZTF.dcl`：字体搜索器对话框界面定义。
- `V6/`：AICAD 扩展、桥接脚本和功能区 DLL，固定安装位置为 `E:\366256\ZW-auto_lisp\V6`。
- `命令索引.md`：自动生成的命令、文件和行号索引。
- `gen_命令索引.py`：命令索引生成脚本。

## 图纸窗口管理器

输入 `DWGWIN`，或点击 Ribbon 工具区的“图纸窗口”，唤起独立的单实例管理器。相同 Windows 用户及登录会话中的多个 ZWCAD 2026 共用一个窗口，列表显示每张图纸所属 CAD；双击会激活对应图纸并将所属 CAD 带到前台，保持双屏布局。支持搜索、排序、备注、收藏、打开目录和明确选择保存或丢弃后关闭。窗口默认不置顶，可切换置顶并记住位置。

每个 CAD 都需要加载新版 `V6/AICADRibbonHostV6.dll`；未加载代理的 CAD 显示未连接。已加载旧 DLL 的 CAD 需要在保存工作后重新启动，单纯重新加载 LISP 无法替换已加载的 .NET 程序集。关闭管理器不关闭 CAD，关闭某一个 CAD 不影响其他实例。

管理器 `V6/DwgWindowManager.exe` 和插件通过本机命名管道通信，不开放网络端口。备注由独立管理器统一保存在 `%APPDATA%\ZW-auto_lisp\window-notes.json`，保留历史格式，按完整路径关联；未保存图纸使用会话备注。构建命令为 `powershell -NoProfile -ExecutionPolicy Bypass -File V6/build_zwcad_ribbon.ps1`，同时生成 DLL 和 EXE。详细验证结果见 `V6/WindowManager/VALIDATION.md`。

## 运行时加载

CADTools/YS-Tools 已从 ZWCAD 支持目录、启动文件和 APPLOAD 注册表中卸载，不再参与命令加载。不要重新部署该工具箱，否则可能覆盖整合版本中的同名命令。

ZWCAD 启动套件只保留 `AA整合版本.lsp` 和 `V6/aicad_aa_loader.lsp`。AICAD 的默认目录及 `AICADAA_BASEDIR` 均应指向 `E:\366256\ZW-auto_lisp\V6`。

## 开发约束

项目统一使用 `main` 作为交付和同步分支。以本地确认的版本为准；工作分支完成后合并并推送到 `origin/main`，再切回 `main`。远程更新脚本从 `main` 拉取。

所有项目文本统一使用 UTF-8 无 BOM；`.lsp` 及 CAD 相关文本文件使用 CRLF 换行。ZWCAD 2026 中需将 `LISPSYS` 设为 `1` 并重启后加载。修改主文件前必须做字节级备份，写入后检查 UTF-8、无 BOM、CRLF 和括号结构。详细规则见 [`AGENTS.md`](AGENTS.md) 或 [`CLAUDE.md`](CLAUDE.md)。

命令入口有增删或代码行号明显变化后，在项目根目录运行：

```powershell
python gen_命令索引.py
python gen_命令索引.py --check
python tools/check_all_static.py
```

`check_all_static.py` 会串起编码/换行、整文件表达式解析、命令清单、undo 配对，以及 FDX/CC/DES/GTX/XY 各专项检查。也可单独运行：

```powershell
python tools/check_fdx_static.py
python tools/check_cc_static.py
python tools/check_des_static.py
python tools/check_gtx_static.py
python tools/check_xy_static.py
```

以上检查不启动 CAD。未经用户明确要求，不得通过 COM、脚本或界面自动化连接 CAD 做验证、加载或切换图纸；静态检查通过不等于 CAD 实机验收通过。
