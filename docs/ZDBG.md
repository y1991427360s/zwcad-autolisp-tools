# ZDBG 文字生成表格

重新加载 `AA整合版本.lsp` 后，输入 `ZDBG`，框选一张表格的全部文字并确认；也可以预选文字再输入命令。

- 自动识别现有文字的行列，保留上下、左右顺序，缺少文字的单元格留空。表头在下方时仍保留在下方。
- 单行文字占高度 5；同一单元格内有 2、3、4 个文字时，分别需要 10、15、20，以此类推。整行高度取各单元格所需高度的最大值，其余行保持各自所需高度。
- 同一格内的多个文字按原来的上下顺序排列，等高时按左右顺序；每个单行文字间距为 5。文字组整体垂直居中，同一行的单个文字也垂直居中。
- 较高的 MTEXT 或 TEXT 按实际外包框高度加上下共 1 的留白，向上取整到 5 的倍数；与其他文字同格时累加所占高度，不修改文字内容或拆分 MTEXT。
- 每列宽度为该列最宽文字的实际外包框宽度加 6，左右各留 3；文字的外包框水平居中。
- 使用原有 TEXT/MTEXT，不修改内容、字高、样式、颜色或对齐属性。表格左边从原文字最左外包框向左扩 3；底边为原最下文字中心向下 2.5，新增高度向上扩展。
- 新建完整外框和每行、每列分隔线，使用当前图层的普通 LINE 图元和 ByLayer 颜色；整个操作可按一次 `U` 撤销。

适用于已大致排成行列、位于 WCS XY 平面且同标高的文字。行列识别容差为平均字高的 0.6 倍，最小 0.5；同一行列分组内的多个文字会排列到同一单元格，不再因文字数量停止。超过行识别容差的文字仍识别为不同表格行。锁定图层、标高不同或无法读取外包框时停止，不修改文字。

只选择表格内文字（含表头），不要包含表格外的标题；例如“设  备  材  料  表”会被识别为额外行列。命令不会删除原有表格线，重复运行会叠加新线，不适用于修改已有完整表格。已有表格的自动列宽请用 `ZDWI`。

离线验证：`python tools/check_zdbg_static.py`。执行实际 LISP 布局函数，原 50 个 QW3 文字仍为 9 行、6 列、4 个空格、总高 45；新增用户提供的 183 个文字数据，验证原冲突单元格使对应行增高至 10，全部文字保留。还检查 10/15/20 行高、文字组及单文字居中、较高 MTEXT、选择顺序和坐标平移。未连接或操作 CAD，实际字体外包框刷新和显示效果尚未在 ZWCAD 验证。
