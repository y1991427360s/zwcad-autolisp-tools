# SSS 表格行高调整

- 使用当前中望项目的 `AA整合版本.lsp`，重载后生效。
- 先用交叉窗口框选要拉伸的对象，窗口下边界穿过需要调整高度的那一行，再执行 SSS。
- 调整窗口下边界所在行的高度，窗口内上方对象按高度差整体上移或下移，沿用 STRETCH 的交叉选择语义。
- 能恢复原交叉窗口时，完整保留其左右、上下边界，不另建表头窗口。
- 预选集未保留窗口信息时，以预选中最低的主要横线作为目标行上边线，查找它下方相邻横线；拉伸沿用原选择集，不再自动切换到表头。
- 请让窗口下边界落在行内，避免压在横线上。整表包围选择没有明确的被穿过行，不再默认修改表头；找不到匹配横线时提示并保持图形不变。
- 上下边线允许分属不同图层，分段横线同样支持。
- 输入正数目标高度，支持小数，回车默认 10。一次撤销可恢复。
