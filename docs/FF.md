# FF 轻量文字替换

1. 预选要处理的单行文字或多行文字。
2. 输入 `FF`，按空格。
3. 输入查找内容，按空格。
4. 输入替换内容，按空格，立即完成。

仅在本次选中文字中进行区分大小写的字面匹配，每个文字中的所有匹配片段均替换，其余内容不变。不使用通配符，不读取剪贴板，不打开面板。未预选时会先提示选择文字。

查找内容留空退出；替换内容留空表示删除匹配片段。输入中的空格用于确认，因此该命令不支持输入含空格的查找或替换内容。按 Esc 取消，整次修改可用一次 `U` 撤销。

支持 TEXT / MTEXT，混选的其他图元不处理；锁定图层或写入失败的对象跳过并报告数量。MTEXT 整体读取 DXF 3/1 段后替换并重新分段；匹配以原始文本串为准，跨格式控制码的可见文字不保证匹配，不承担格式清洗。

修改位于当前中望项目 `AA整合版本.lsp`，用户重新加载后生效。仅做离线检查，未进行 CAD 实机验证；AutoCAD 2018 待用户要求同步。
