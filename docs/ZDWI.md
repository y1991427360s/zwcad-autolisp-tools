# ZDWI 自动调整表格列宽

选择整张由直线或多段线组成的水平表格及文字，执行 `ZDWI`；也可以预选表格中的一条完整横线，由命令查找相连表格。

- 每列按完整文字包围盒的最大宽度计算新列宽，左右各留 3 个图纸单位；同次执行既可放宽，也可缩窄。
- 文字即使越过整张表格的左右边框，只要包围盒中心位于表内且竖向范围在表内，仍参与列宽计算；归列按文字包围盒中心判断。
- 保持表格左边界、行高和文字大小，调整表格线并将文字水平居中；一次 `U` 可整体撤销。
- 本命令适用于轴线对齐的线框表格，文字支持 TEXT/MTEXT；不是原生 TABLE 对象的列宽工具。
