# HWT：柜名列一键生成环网图

重新加载当前项目的 `AA整合版本.lsp` 后，输入 `HWT`。

1. 框选一列柜名单行文字（多行文字也可），按从上到下的顺序作为环网顺序；同一高度再从左到右。
2. 命令行显示柜数和分行，例如 `共 13 个柜，分行 5/4/4`。
3. 点取第一行第一个柜框的左上角，生成整张环网图。
4. 再点电缆清单的左上角（回车放在环网图左下方），生成电缆清单。环网图和清单一次 `U` 一起撤销。

## 排版规则

- 每行最多 5 个柜：行数 = 向上取整(柜数/5)，各行数量尽量相等，多出的放在前面几行（13 → 5/4/4，11 → 4/4/3，6 → 3/3）。
- 蛇形走线：第一行从左到右，第二行从右到左，依此交替；较短的行以第一行为中线居中，整体左右对称。
- 柜框 34.72×18，分三格：柜名 / L1、N1 / 端子号。柜距 60.76，行距 45。柜名太长时自动压缩宽度系数，不压线。
- 每个柜两个端子圆，各引一长一短两条斜线到上下两条母线，交接处画实心点；同一行内相邻柜交替从下线进上线出、从上线进下线出，每行第一个柜都从下线进。

## 文字与编号

- 柜间电缆按环网顺序编号 `SML-01`、`SML-02`……（行与行之间的竖向连线也占一个号，标在竖线内侧），规格一律 `2×4`。
- 环首进线固定 `JL-01`，环尾进线固定 `JL-04`，都标注 `至交流馈线柜` 和 `2×4`，并画空心三角箭头；两段进线为绿色（颜色 3）。
- 端子号一律默认 `JD：1~2`（L1）和 `JD：4~5`（N1），个别柜（如主变测控柜的 `JD：10~11`）出图后手改。
- 文字为 HZ 样式、字高 3、宽度系数 0.7、居中对齐；柜内文字为青色，进线文字随层。图中没有 HZ 样式时改用当前文字样式并提示。全部图元画在当前图层，端子圆为白色（颜色 7）。

## 电缆清单（供 BH3 登记）

每根电缆一行，共 柜数+1 行，列顺序与 BH3/HDDL 清册一致：起点柜、电缆编号、终点柜、规格、芯数、原理号。

| 起点 | 编号 | 终点 | 规格 | 芯数 | 原理号 | |
|---|---|---|---|---|---|---|
| 交流馈线柜 | JL-01 | 第 1 个柜 | 2×4 | 2 | L1 | N1 |
| 第 1 个柜 | SML-01 | 第 2 个柜 | 2×4 | 2 | L1 | N1 |
| …… | | | | | | |
| 最后一个柜 | JL-04 | 交流馈线柜 | 2×4 | 2 | L1 | N1 |

文字为白色、HZ/3/0.7、左中对齐，行距 5（同 H/HWD），列宽取该列最长文字、列间空 10。框选整份清单运行 `BH3` 即可按“两端柜名 + 原理号 L1 N1”登记编号。

## 检查

离线检查：`python tools/check_hwt_static.py`。它用 `tools/lisp_mini_eval.py`（只支持纯计算的 AutoLISP 子集）直接执行 `hwt:layout`，核对分行、SML/JL 编号、端子与实心点数量和各行居中。未做 CAD 实机验证。
