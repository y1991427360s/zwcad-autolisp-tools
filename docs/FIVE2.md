# FIVE2：表格统一行高 5

重新加载当前项目 `E:\366256\ZW-auto_lisp\AA整合版本.lsp` 后输入 `FIVE2`，完整框选同一列上下相接的表格（全部直线、文字和圆符号），回车确认。也支持预选。

- 包括标题行、表头和正文行，均改为 5 个图纸单位。合并单元格跨几行，修改后仍跨对应行数。
- 固定整列最上边，向下重排行边界，更新竖线和文字位置。列宽、文字内容、字高、样式、颜色、图层及圆半径保留。
- 同位置重复横线只计一次行边界，原实体保留；共边表格一起调整，保持相接。
- 文字按可见中心所在行垂直居中；圆符号平移，接圆的短线端点随圆移动。
- 一次 `U` 整体撤销。执行途中报错或取消后，使用 `U` 撤销本次已有修改。

适用于 WCS XY 平面内、同一标高的直线表格，以及 TEXT、MTEXT、CIRCLE 内容。不同列或有间隔的表格分次选择。块、原生 TABLE 和多段线表格不在此命令范围内。锁定图层、缺失边框或文字可见高度超过 4.8 时拒绝修改。

横线先合并共线分段，再将长度不少于整列宽度 20% 的水平线识别为行边界；很短的局部单元格分隔线可能无法自动识别，使用前应检查是否符合此条件。框选务必包含整列所有内容，未选入的对象不会跟随移动。

离线检查：`python tools/check_hg5_static.py`。仅完成源码与提供的 QW3 数据离线验证，未经用户要求不连接 CAD。
