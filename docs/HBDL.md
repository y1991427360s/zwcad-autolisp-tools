# HBDL 命令使用说明

## 命令概述

`HBDL`（合并）是用于电缆清册表格并入行就地合并的命令。

在电缆清册制表过程中，常常存在部分电缆带有“并入”前缀（如 `并入1(2)-1SR-163`），需要将其与对应的目标主电缆（如 `1(2)-1SR-163`）合并为同一行：
- **电缆编号**：保持目标主电缆编号不变；
- **芯数累加**：自动定位规格（如 `4×2.5`）右侧的第 5 个数字（芯数），将并入行的芯数累加至主电缆（例如 $3 + 1 = 4$）；
- **原理号往后堆积**：保持主电缆原有的原理号顺序不变，将并入行后面的原理号自动往后依次追加堆积（例如原主电缆为 `BS03, BS04, BS01`，并入行为 `BS02`，合并后为 `BS03, BS04, BS01, BS02`）；
- **就地合并**：被合并的并入行文字自动删除，其他未参与合并的文字保持原位，无需新建表格。

---

## 核心规则与工作流程

1. **表格行聚类与顺序识别**：
   - 框选电缆清册表格文字后，按文字垂直标高（Y 坐标）智能聚类为各行（容差基于文字高度动态适配）；
   - 行内文字按水平方向（X 坐标）从左到右升序排列。

2. **智能字段识别**：
   - **芯数列定位**：从左往右第 5 个文字（即规格 `4×2.5` 右侧第 1 项），程序亦会自动校验其数值与右侧原理号数量的一致性；
   - **电缆编号定位**：自动识别带有“并入”或处于前缀大字与去向之间的电缆编号；
   - **目标编号提取**：剥离“并入”及可能带有的标点符号（如 `并入1(2)-1SR-163` 提取出 `1(2)-1SR-163`）。

3. **智能并入合并（纯就地修改）**：
   - 在同前缀/同屏柜分类下，将并入行精准对齐到对应的目标主电缆行；
   - **芯数就地修改**：直接通过 `entmod` 修改主电缆芯数文字（例如将 `3` 原地修改为 `4`），完全保持原文字属性；
   - **原理号往后堆积**：保留主电缆原有的原理号顺序不变，在末尾按列宽依次生成并入行的原理号（例如追加 `BS02`）；
   - **消除并入行**：被合并的并入行所有文字图元自动删除；
   - **其他文字完全不动**：除目标主行和被删除的并入行外，选区内所有其他未参与合并的文字图元**绝对保持原位，丝毫不动**。

4. **单次 U 整体撤销**：
   - 严格遵循项目的 `aa:cmd-begin` / `aa:cmd-end` 事务规范，在 CAD 中输入 `U` 即可一次性撤销全部操作。

---

## 快捷操作步骤

1. 在 CAD 命令行输入 `HBDL` 并回车（亦可提前框选文字再输入 `HBDL`）；
2. 框选需要合并的电缆清册表格文字，回车确认；
3. 程序瞬间在原图上就地完成修改（芯数更新、原理号追加、并入行删除，其他所有文字不动），命令行输出完成提示：
   `[HBDL] 原地合并完成：成功合并 1 个并入行。主电缆芯数已更新，原理号已向后堆积追加。`
