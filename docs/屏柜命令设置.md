# 屏柜命令设置面板

双击项目根目录的 **屏柜命令设置.cmd**，即可打开独立设置窗口。需要本机 Python 3.10+（含 tkinter），无需安装第三方包，不连接 CAD。

## 修改现有命令

1. 在左侧选中需要设置的屏柜命令，包括 KMZ/KMY、LNZ/LNY、UPSZ/UPSY、BZ/BY、485Z/485Y、ZJ/YJ、YDZ/YDY 和 LBZ/LBY。
2. 修改“柜内文字”，例如把 KMZ 的“直流馈线柜”改成“直流电源柜”；UPSZ 可改成“UPS馈线柜”或“1号电源馈线柜”。也可分别修改上方标注、下方标注和生成方向。
3. 编辑时右侧示意图实时变化。点击“保存全部设置”，等待静态检查成功。
4. 自行在 CAD 重新加载窗口顶部显示的 `AA整合版本.lsp`，之后运行命令使用新设置。此前已画出的图形不会改变。

左右命令独立保存，例如修改 KMZ 不会连带修改 KMY。文字高度、颜色、线型及几何规则继续采用现有共用绘图函数，示意图不代表 CAD 实际尺寸。

YDZ/YDY、LBZ/LBY 使用自动编号：可编辑“首个编号”和“后续编号前缀”。例如 LBZ 的 `500` 与 `-5` 生成 `500、-501、-503……`；复制为新命令会保留原编号类型。

## 增加同系列命令

选中一条相近命令，点击“复制为新命令…”，输入新命令名，例如 `DYZ` 或 `UPSFZ`。修改文字和方向，保存后重新加载，就可直接输入新命令使用。已有同系列命令会自动列出，不需要手动加入面板。

命令名只能使用英文字母、数字、下划线，以字母或数字开头且至少含一个英文字母，最多32位；自动转为大写，例如 `485Z`。不能与任何现有命令冲突。本面板不支持删除或改名已有命令。

`485Z` 向左、`485Y` 向右，与 BZ/BY 共用绘图逻辑；上方标注为 `485+`，下方为 `485-`，柜内文字为“网络通信柜”。

## ZJ / YJ 的剪贴板柜名

运行 `ZJ` 或 `YJ` 后，提示“柜内文字来源”：回车默认读取 Windows 剪贴板中的文字；输入 `M`（Manual）后可手动填写柜内文字，支持空格。手动输入时回车使用面板中的“手动默认柜名”（初始为“终点柜名”）。

剪贴板为空、非文字或读取失败时停止，不绘图；可重新运行并选择手动输入。文字首尾空白会去除，换行和制表符转换为空格。两侧方向、短线上方的“原理号”、颜色线型、矩形自适应及一次撤销规则不变。

设置面板中的 ZJ/YJ“手动默认柜名”仅用于手动输入时的回车默认值；默认剪贴板模式每次运行都会重新读取，不在面板打开或预览时读取。预览使用占位文字，保存设置和复制为新命令均保留此行为。

## 保存与恢复

- 面板只编辑启动脚本所在项目的整合文件，顶部显示完整路径；当前项目为 `D:\Syncthing\Oracle-Sync\LISP\ZW-auto_lisp`。现有 Excel/AHK 面板的重载路径也指向这里；手工 APPLOAD 时请核对路径。
- 保存前严格检查 UTF-8 无 BOM、CRLF、整文件表达式和命令结构，自动创建 `backups/cabinet-panel-时间戳/` 字节级备份。
- 保存同步更新整合文件开头命令清单及命令旁注，重新生成两份命令索引、工程审计文档和 JSON，然后运行 `scripts/check_project.py` 全仓静态检查。失败时恢复保存前的整合文件及生成文档。
- 若整合文件在面板打开后被其他程序修改，保存会停止；重新打开面板读取新版本，避免覆盖外部改动。
- 保存时禁止关闭面板；未保存退出时提示放弃草稿。多面板不能同时保存。异常中断可能留下根目录 `.cabinet-panel.tmp`，确认没有面板在保存后可删除该锁文件。
- 如需恢复某次成功保存前的版本，关闭面板，把对应备份里的 `AA整合版本.lsp` 复制回项目根目录，再运行 `python gen_命令索引.py` 和 `python scripts/audit_lsp.py --write`，重新打开面板。
- 保存不会自动加载 CAD、执行命令或推送 Git。若需把自己的后续设置同步到远程仓库，可按项目的 main 分支流程提交推送。

验证边界：Python 编辑、预览、文件事务和 LISP 静态检查可离线验证；未经用户明确授权不做 CAD 验证。

## 防止新增命令遗漏

- 同系列命令从源码自动发现，无需维护命令名白名单。
- 面板另行检查屏柜绘图函数的直接及间接调用关系，以及命令清单中同时包含“柜”和“矩形”的条目。如果发现属于屏柜系列但无法编辑的入口，打开或保存会报出命令名，要求补齐适配，不会静默隐藏。
- 新处理函数若复用 `aa:km-create-centered-text`，同样纳入检查。完全独立实现的屏柜命令必须增加一行 `;;; Cabinet-Panel: 命令名`，并同时实现面板适配及回归；静态分析不能自动判断任意独立实现的业务含义。
- 独立检查：`python tools/check_cabinet_panel_static.py`。已接入 `tools/check_all_static.py`，全仓入口 `scripts/check_project.py` 的单元回归也会检查实际整合源码。
- 回归包含未来新命令自动出现、包装结构变化、新处理函数、间接调用、显式声明和模拟遗漏自动编号适配等情况。新增命令时必须执行检查，不能只更新命令索引。
