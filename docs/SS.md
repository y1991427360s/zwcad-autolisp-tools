# SS 正交动态拉伸

重新加载当前项目的 `AA整合版本.lsp` 后输入 `SS`。

1. 从右往左交叉框选需要拉伸的端点/部分，回车结束选择；也支持已有预选。
2. 指定基点，保留原来的对象捕捉。
3. 鼠标朝水平或竖直方向移动，实体随鼠标实时显示拉伸效果。第二点和原生 STRETCH 一样可用：
   - **输入距离**：鼠标指向方向后直接键入数值回车，按正交方向拉伸该距离；
   - **对象捕捉 / 对象捕捉追踪**：沿用用户当前的捕捉与追踪设置。悬停捕捉点后沿水平/竖直方向移动可得到对齐点；
   - **直接点击偏斜的捕捉点**：CAD 原生规则下捕捉点会覆盖正交，拖动预览会暂时显示斜向。点击后命令自动将位移投影到主方向（X、Y 分量中绝对值较大的方向），另一分量与 Z 清零，即拉伸到与该点水平/竖直对齐的位置。
   Esc 取消。

实现：第二点交给原生 STRETCH 动态拖动（DRAGMODE=2、正交开、栅格捕捉关、网格角度归零），不再关闭对象捕捉和自动追踪。完成后统计选择集图元点位变化，取出现次数最多的一组位移（圆弧、椭圆、填充不参与统计，避免拉伸变形干扰；无点位变化时读 LASTPOINT）。位移偏斜时，先用拉伸前快照（含属性与旧式多段线顶点）以 entmod 精确还原，再按投影后的第二点重新执行原生 STRETCH。第二点直接回车会被原生命令当作“以基点坐标为位移”，命令会还原并提示，避免误拉伸。

方向以当前 UCS 为准，适用于日常二维平面图。显式输入斜向坐标（如 `@10,5`）也会被投影为主方向。交叉框只包含部分端点时拉伸；完整包含或逐个点选的对象沿用原生整体移动语义。结束、取消或报错均恢复正交、捕捉、跟踪、栅格捕捉、网格角度、拖动显示与命令回显。一次 U 整体撤销（含自动校正），原 S 不变；SW 为记忆方向与距离的拉伸。

极轴追踪：命令内部临时打开正交，CAD 会因正交与极轴互斥而清掉极轴（AUTOSNAP 位 8）。结束、取消或报错时由 `aa:ortho-restore-vars` 按原状态排序还原：原正交关闭则先关正交再恢复极轴，原正交开启则先恢复 AUTOSNAP 再开正交，并做两遍确保两项都回到原值。
