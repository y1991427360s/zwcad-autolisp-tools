# GTX 电缆文字分类汇总

加载当前项目的 `AA整合版本.lsp` 后运行 `GTX`。

1. 预选或框选需要整理的单行文字、多行文字。
2. 选择一个汇总前缀文字对象；框选多个对象会要求重新选择。
3. 指定汇总插入点。

容差自动计算，无需输入或确认：同行容差为所选文字字高中位数的三分之一，处于容差边界的文字归入同行；横向拆组净间距为字高中位数的 `200/3` 倍。字高为 3 时，两者分别为 1 和 200。相邻文字包围盒边缘间距超过自动阈值才拆组。

同行判断使用 WCS 包围盒垂直中心，先从上到下排序，再以每行首项固定为基准，避免选择顺序变化或连续微小偏移导致串行。同行内按包围盒左边缘排序，不再受 TEXT 插入点对齐方式影响。规则适用于水平排布的表格；旋转表格需先按实际布局调整，命令不会自动识别表格方向。

分类键去除首尾空白、开头的“并入”，统一大小写与常见横杠，按最后一个横杠之前的部分分类。输出保留文字原内容，多行文字格式标记去除、段落合并为空格。编号按连续数字段自然排序，重复内容保留。

输出字高为 3，列距至少为 50，按最长内容自动加宽。输出按 WCS 水平排布，插入点从当前 UCS 转换到 WCS，并保留其高程。空文字和无法读取包围盒的对象会跳过并报告数量。创建失败会提示，已生成内容与正常汇总均可用一次 `U` 撤销。

静态验证：`python tools/check_gtx_static.py`。此检查解析整文件并执行分行、净间距拆组和自然排序的实际源码表达式，不连接 CAD；不能替代中望中的实际字体、包围盒与显示验证。
