# XYG 命令使用说明

## 命令概述

`XYG` 是将 **XY**（绿色水平线芯数统计与原理号文字横向排列）与 **GTX**（电缆文字自然排序与分类汇总表格生成）无缝串联的复合自动化命令。

用户只需**一次性大范围框选**图面区域，程序将自动完成前缀大字提取、绿色水平线统计、文字提取与关联排版，并在点击输出点后生成规范的电缆清册汇总表格。

---

## 核心规则与工作流程

1. **自动识别绿色直线与几何去重**：
   - 框选多个对象后，自动识别出所有颜色为绿色的水平直线（支持 ACI 3、TrueColor 及随层绿色）；
   - 自动进行同标高/同端点几何去重（`xyg:dedup-hlines`），防止图纸重复画线导致重复统计。
2. **自动提取前缀大字（GTX 第二次选择）**：
   - 在选区内查找所有文字高度 $\ge 80$ 的大字；
   - 自动选取其中**最左侧（X 坐标最小）**的大字作为电缆分类前缀（如柜名/屏号）。
   - 若选区内未框进大字，自动提示手动点选，防止中断。
3. **自动运行 XY 命令**：
   - 在每条绿色直线右侧添加芯数统计数字（由 `XIN` 逻辑生成）；
   - 在直线右侧水平向右排列提取到的关联原理号文字（由 `YUAN` 逻辑生成）。
4. **右上方 3 个文字与右侧文字精准提取（GTX 第一次选择）**：
   - 绿色直线行距为 5mm，以每条绿色直线右端点为基准，往左 150mm（带容差扩展至 155mm）、**往上 3mm**（`ry - 0.5` 至 `ry + 3.5`）构建搜索矩形框；
   - **外包盒相交与双重检索保障**：
     - 提取右上方电缆信息时优先从框选集提取，不足 3 个文字时自动在 150mm×3mm 矩形框内向图面检索补充；
     - 采用 ActiveX `vla-getBoundingBox` 与原生 `textbox` 双重回退机制，确保准确获取文字几何范围；
   - 从右侧顶点往左看严格只提取最靠近右侧的 3 个水平文字（电缆编号、去向、规格）；
   - **右侧多栏/同行智能隔离防重复机制**：
     - 若同一水平标高存在多列/多个设备（如左侧 1SR 与右侧 2SR 在同一行），自动以右侧邻近直线的左端点作为硬性右边界，严禁跨列抓取；
     - 依据首个芯数数字 $N$（或 `XIN` 统计值）执行精确截断，每组严格只取 $1 + N$ 个文字（1 个芯数 + $N$ 个原理号）；
     - 相邻文字间距突增（$> 50\text{mm}$）立即连续性截断；
   - 将这 3 个文字与右侧添加的数字、原理号拼接成一条完整电缆数据：
     `[电缆编号] [去向] [规格] [芯数] [原理号1] [原理号2] ...`
5. **执行 GTX 汇总输出**：
   - 提示用户指定插入点：`请指定汇总结果的插入点: `；
   - 自动按电缆编号分类并进行自然排序（Natural Sort）；
   - 生成带前缀大字的整齐排版电缆清册汇总表格。
6. **一次 Undo 整体撤销**：
   - 整个流程处于同一个 Undo 标记内，在 CAD 中按一次 `U` 即可整体撤销所有生成的文字。

---

## 快捷操作步骤

1. 在 CAD 命令行输入 `XYG` 并回车；
2. 鼠标框选包含左侧大字、绿色直线及电缆文字的目标区域，回车确认；
3. 命令行显示识别进度并提示指定插入点；
4. 鼠标在图面空白处点击一下，表格即刻生成。
