# XYG 命令使用说明

## 命令概述

`XYG` 是将 **XY**（绿色水平线芯数统计与原理号文字横向排列）与 **GTX**（电缆文字自然排序与分类汇总表格生成）无缝串联的复合自动化命令。

用户只需**一次性大范围框选**图面区域，程序将自动完成前缀大字提取、绿色水平线统计、文字提取与关联排版，并在点击输出点后生成规范的电缆清册汇总表格。

---

## 核心规则与工作流程

1. **自动识别绿色直线与几何去重**：
   - 框选多个对象后，自动识别出所有颜色为绿色的水平或竖直直线（支持 ACI 3、TrueColor 及随层绿色；2026-10-28 起支持竖直绿色电缆线、水平引线与竖排端子排上的水平原理号）；
   - 2026-10-30 起一次框选可同时处理水平和竖直电缆线。两种都有时，绿色竖线要端点不落在绿色横线上（否则是芯线）且连着横引线才算电缆，其余跳过并在命令行报告数量；只有一种方向时全部保留。JM、BH 系列仍按“有水平线就只处理水平线”；
   - 自动进行同标高/同列、同端点几何去重（`xyg:dedup-hlines`），防止图纸重复画线导致重复统计。
2. **自动提取前缀大字（GTX 第二次选择）**：
   - 在选区内查找所有文字高度 $\ge 80$ 的大字；
   - 自动选取其中**最左侧（X 坐标最小）**的大字作为电缆分类前缀（如柜名/屏号）。
   - 若选区内未框进大字，自动提示手动点选，防止中断。
3. **自动运行 XY 命令**：
   - 在每条绿色直线右侧添加芯数统计数字（由 `XIN` 逻辑生成）；
   - 芯线允许偏离竖直方向最多 1°（独立参数 `*xy-vline-ang-tol*`），零长度线及明显倾斜的短斜线不计入；
   - 仅芯线端点与绿色横线连接时计数，连接与去重容差仍为 0.0001，不把穿越横线当连接；
   - 连接端、远端分别保留真实坐标：按连接端分桶、去重和输出排序，按远端搜索原理号，兼容倾斜与交叉；
   - 在直线右侧水平向右排列提取到的关联原理号文字（由 `YUAN` 逻辑生成）。
4. **右上方 3 个文字与右侧文字精准提取（GTX 第一次选择）**：
   - 绿色直线行距为 5mm，以每条绿色直线右端点为基准，往左 150mm（带容差扩展至 155mm）、**往上 3mm**（`ry - 0.5` 至 `ry + 3.5`）构建搜索矩形框；
   - **外包盒相交与双重检索保障**：
     - 提取右上方电缆信息时优先从框选集提取，不足 3 个文字时自动在 150mm×3mm 矩形框内向图面检索补充；
     - 采用 ActiveX `vla-getBoundingBox` 与原生 `textbox` 双重回退机制，确保准确获取文字几何范围；
     - 每个文字的包围盒在一次命令内只计算一次，矩形查询走预建索引，详见下文“大图性能”；
   - 从右侧顶点往左看严格只提取最靠近右侧的 3 个水平文字（电缆编号、去向、规格）；
   - **右侧多栏/同行智能隔离防重复机制**：
     - 若同一水平标高存在多列/多个设备（如左侧 1SR 与右侧 2SR 在同一行），自动以右侧邻近直线的左端点作为硬性右边界，严禁跨列抓取；
     - 依据首个芯数数字 $N$（或 `XIN` 统计值）执行精确截断，每组严格只取 $1 + N$ 个文字（1 个芯数 + $N$ 个原理号）；
     - 相邻文字间距突增（$> 50\text{mm}$）立即连续性截断；
   - 将这 3 个文字与右侧添加的数字、原理号拼接成一条完整电缆数据：
     `[电缆编号] [去向] [规格] [芯数] [原理号1] [原理号2] ...`
   - **并入电缆自动合并**（2026-10-30 起）：编号写成 `并入X` 的线并到本次框选里同编号、同去向的主电缆行，芯数相加、原理号接在主电缆后面，汇总表里只有一行，不用再跑 `HBDL`。多根并入线按图上从上到下的顺序接。找不到主电缆（不在本次框选里或去向不同）时保留 `并入X` 行并在命令行提示，这种跨框选的情况到总表上再用 `HBDL`。只合并汇总表，图上的 XY 文字不动。
5. **执行 GTX 汇总输出**：
   - 提示用户指定插入点：`请指定汇总结果的插入点: `；
   - 自动按电缆编号分类并进行自然排序（Natural Sort）；
   - 生成带前缀大字的整齐排版电缆清册汇总表格。
6. **一次 Undo 整体撤销**：
   - 整个流程处于同一个 Undo 标记内，在 CAD 中按一次 `U` 即可整体撤销所有生成的文字。

## 大图性能（2026-10-17）

旧实现对每条绿色直线都把整个框选集扫一遍，并对每个小字重新调用一次 COM 包围盒（命中时再调一次）。总调用量约为“直线数 × 文字数”，大图（数千个对象）上会让中望无响应好几分钟。

现在的做法：

- **选区小字只算一次包围盒**：XY 完成后，`xyg:build-text-index` 把选区中字高 < 80、纯文本非空的 TEXT/MTEXT 采集成记录 `(原序号 图元 xmin xmax ymin ymax 中心X 纯文本)`，按 ymin 排序后建成平衡包围盒树（`xyg:index-tree`，每个节点保存整棵子树的范围）。每条直线的右上矩形只查这棵树（`xyg:query-text-index`），命中结果再按原序号恢复顺序，所以同 X 并列时的取舍和逐个扫描完全一样。
- **XY 新文字按插入点建树**：右侧芯数和原理号同样建一棵树，先按放宽的 Y 带查询，再执行原来的精确判定（`x > rx+0.5`、`x <= limit-x`、`|y-(ry+0.5)| <= 0.6`）。
- **直线几何只读一次**：直线排序先取 Y 再排（`xyg:sort-lines-desc`）；右侧邻线边界从缓存的 `(图元 Y 左端X)` 列表中查找（`xyg:next-line-min-x`），列表按 Y 从大到小排列，Y 已低于本线 0.5 以上时提前结束。
- **不变的规则**：只取最靠右的 3 个文字、选区不足 3 个时窗口补查、字高 ≥ 80 排除、包围盒相交判定、右侧邻线边界、芯数截断、间距截断，以及 AA_LINK 联动继承（`*xyg-rect-src*` / `*xyg-right-src*` 与返回文字一一对应）。窗口补查可能取到 XY 新生成的文字，所以仍在查询时实时读取。
- 两棵索引都是 `c:XYG` 的局部变量，命令结束即释放，不跨命令缓存，也不新增持久 COM 引用；共用的 `xy:get-text-bbox` 本来就会释放临时 VLA 对象，本次未改。排序只用 `aa:merge-sort`。
- **离线验证**：`tools/check_xyg_static.py` 内嵌优化前的 LISP 原文作为对照，在 60 个随机场景中执行新旧两版的实际函数（覆盖边界接触、同 X 并列、包围盒读取失败、大字、空文字、窗口补查、同排多列、Y 带 ±0.6 边界和邻线 0.5 边界），结果与联动来源全部一致；这些场景的包围盒请求从 12064 次降到 1155 次。这是请求次数对比，不是 CAD 中的实测耗时。
- **尚未实机验证**：中望实图上的耗时和内存需要用户重载插件后验收。XY 本身（XIN/YUAN）的耗时这次没有改动。

## 快捷操作步骤

1. 在 CAD 命令行输入 `XYG` 并回车；
2. 鼠标框选包含左侧大字、绿色直线及电缆文字的目标区域，回车确认；
3. 命令行显示识别进度并提示指定插入点；
4. 鼠标在图面空白处点击一下，表格即刻生成。

## 文字联动：SX / SX1（2026-10-17，取代当日的 XYGS）

改原件端子排后，草稿、XY 副本、XYG 汇总、GTY 汇总四层文字一键同步，只同步文字内容。

**原理**：原件文字带唯一编号（XData `AA_LINK` = 图纸 ID + 原件句柄）。原生 COPY 复制草稿、GTY 生成副本时，都会自动带上这个编号；XY 和 XYG 新建文字时也会继承。图纸 ID 和句柄都等于自身的那个文字是原件，其余同编号的文字都是副本。

**流程**：
1. 画好原件端子排后执行 `SX`，框选原件里的全部文字（包括电缆编号、去向、规格、原理号、柜名大字）。每张原件只需标记一次，重复执行只给新文字发编号；草稿等副本会被跳过，不会变成原件。 有新标记且图已保存时，`SX` 同时更新 dwg 旁的值文件（2026-10-30 起）。
2. 照常复制草稿 → `XYG` → `GTY`。
3. 修改原件文字后执行 `SX1`，全图副本按原件内容更新。命令行会报告原件、副本、已更新和原件缺失的数量，一次 `U` 可整体撤销。副本按记录的原件句柄直接定位原件（`handent`），不再逐个比对原件列表；结束时显示分段用时（扫描 / 刷新 / 导出）。原件在其他图纸的副本（从别的图粘贴过来的）只计数，并提示改用 `SX2` 刷新。
4. 如果改的是电缆编号这类影响排序的文字，`SX1` 之后再重跑一次 `GTY` 即可重新排序（新副本同样带编号）。

**限制**：
- 单向联动，改副本不会回写原件；只同步内容，增删端子等结构变化需要重跑命令。
- 必须在执行 `SX` 之后再复制草稿、跑 XYG；标记之前生成的草稿和汇总文字没有编号。
- XIN 生成的芯数数字没有原件，不联动。
- 原件被删除后，对应副本保持原样，计入“原件缺失”。
- 含组码 3 的超长多行文字不处理。
- 跨图联动见下节 `SX2`。

## 不留痕的汇总：XYG2（2026-10-30）

`XYG2` 的框选、识别、并入合并和汇总表都与 `XYG` 相同，区别只在原图：

- 芯数和原理号读完就删掉，电缆线后面不留文字；
- 文字数和引线数不一致的异常电缆线，只在命令行报告坐标，不改红、不延长。

原件上可以直接跑，不用先复制草稿。一次 `U` 撤销整张汇总表。文字联动不受影响，汇总表里的文字同样带原件标记。

## 跳到原件：SXD（2026-10-30）

核对时发现某个字有问题，在总图输入 `SXD`，点这个字（也可以先选中一个字再输入），就跳到它的原件：

- 原件在本图：缩放到原件并选中。
- 原件在其他卷册图：在上次 `SX2` / `SXD` 用过的文件夹及其下两层，按标记里记的图名找 dwg，打开或切换过去，再缩放到原件并选中。图改过名时再查 `*.aalink.txt`。找不到时提示输入文件夹，回车用默认，`B` 浏览。

前提：原件做过 `SX`，卷册图和总图能在同一个文件夹树里找到。不需要先跑 `SX1`（2026-10-30 起）。目标图里这个句柄已不是带标记的文字时，命令行会说明。XY 芯数和合并后的芯数没有原件，不能跳。

实现：LISP 里切换文档后，SXD 会挂起到用户回到原图才继续，所以打开、切换和定位都不在 LISP 里做。SXD 写两个临时文件后立即结束：`%TEMP%\aa_sxd_jump.lsp`（在目标图里缩放并选中）和 `%TEMP%\aa_sxd_jump.vbs`。VBS 用 `wscript.exe` 脱离 CAD 运行，打开或切到目标图，确认它是活动图且空闲后加载定位脚本，用 `USERS5` 确认完成，最长约 2 分钟，失败时弹窗提示。

实测（2026-10-30，中望 2026）：本图跳转通过。跨图的旧版本在用户总图上切图后不定位，要点回总图才继续；现已改成上述流程，**修改后待用户验收**。

## 清除联动标记：SX0

联动标记会跟着文字走：COPY、Ctrl+C / Ctrl+V（包括粘贴到别的图）、镜像、阵列、GTY 副本、XY 和 XYG 生成的文字，都会带上原件的标记，之后被 `SX1` / `SX2` 刷新成原件内容。想把一段文字挪作他用、不再跟着原件变时：

1. 先正常复制。
2. 对复制出来的文字执行 `SX0` 并框选，删除它们的 AA_LINK 扩展数据，这些文字从此就是普通文字。
3. 框选里混进的原件会自动跳过（清掉原件会让它的全部副本变成“原件缺失”），无标记的文字不处理。命令行报告“清除副本标记 N 个，跳过原件 M 个，无标记 K 个”；锁定图层上清除失败的文字另行提示。一次 `U` 可撤销。

### 强制清除（含原件）：YSSX0

`YSSX0` 与 `SX0` 用法相同，但框选到的原件也会被清除标记，原件和副本全部变成普通文字（命令名加 `YS` 前缀，防止误按）。命令行报告“清除原件标记 N 个，副本标记 M 个，无标记 K 个”，一次 `U` 可撤销。原件标记清除后，没有一起框选到的副本（本图或其他图）就找不到原件，`SX1` / `SX2` 不会再更新它们；需要时再对这些副本执行 `SX0` 清除。

## 跨图联动：SX2（2026-10-17）

多个卷册图的 GTY 文字复制到一张总图、再跑 `GTY` 得到总端子排后，总图也能按各卷册原件刷新。复制粘贴不会丢编号，总图只是缺少原件内容，所以由卷册图把原件内容导出到文件，总图读文件刷新。

**流程**：
1. 每张卷册图：改完原件后执行 `SX1`。本图有原件时，除了刷新本图副本，还会在 dwg 旁写出 `<图名>.aalink.txt`，命令行显示文件路径和原件数量。值文件内容取自当前图面（不是磁盘上的 dwg），所以不必每次先保存；只有从未保存过的新图因为没有文件名而不导出，会提示先保存一次。
2. 总图：执行 `SX2`，指定值文件所在文件夹。直接回车使用默认文件夹（上次用过的，首次为总图所在文件夹）；输入 `B` 弹出文件夹浏览框；也可以直接输入或粘贴路径。会读取该文件夹及其下两层子文件夹里的全部 `*.aalink.txt`。
3. `SX2` 只更新“原件在其他图纸”的副本，只同步文字内容。命令行报告值文件数、跨图副本数、已更新数和“未找到原件值”数，一次 `U` 可整体撤销。总图自己若也有原件，它的副本仍由 `SX1` 刷新。
4. 改了电缆编号等影响排序的文字，`SX2` 之后在总图重跑一次 `GTY`。

**值文件格式**（UTF-8，一行一条，TAB 分隔）：
- 第一行表头 `AA_LINK_VALUES<TAB>1`；
- `P<TAB>UID<TAB>纯文本`：每个原件一行，UID 为“图纸ID|原件句柄”；
- `M<TAB>UID<TAB>原文`：原件是多行文字时紧跟一行，保留格式码，总图里的多行文字副本用它（规则与 `SX1` 相同，超过 250 字符不处理）。
- 内容含换行符的原件不写出。文件可以随卷册图一起放进同步盘，总图那边无需打开卷册图。

**注意**：
- 值文件是执行 `SX1` 那一刻的原件内容；卷册图之后再改原件，要重新执行 `SX1` 才会更新文件。
- 同一编号出现在多个值文件里（例如卷册图另存了一份副本）时，取修改时间较新的文件；内容不一致会在命令行提示“多文件内容不一致 N 处”。
- 卷册图改名后旧值文件仍在，建议删掉，避免旧数据混入。
- 值文件以中望 `open` 的 `utf8` 编码参数读写；若当前环境不支持，自动退回系统默认编码，同一环境下读写仍一致。实机行为待验收。
