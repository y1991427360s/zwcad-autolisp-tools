# HZBG 文字生成表格

重新加载 `AA整合版本.lsp` 后，输入 `HZBG`，框选一张表格的全部文字并确认；也可以预选文字再输入命令。

- 自动识别现有文字的行列，保留上下、左右顺序，缺少文字的单元格留空。表头在下方时仍保留在下方。
- 相邻行文字的外包框中心间距固定为 5，表格每行高度也为 5。
- 每列宽度为该列最宽文字的实际外包框宽度加 6，左右各留 3；文字的外包框在单元格内水平、垂直居中。
- 使用原有 TEXT/MTEXT，不修改内容、字高、样式、颜色或对齐属性。表格左边从原文字最左外包框向左扩 3；最下行中心高度保持原位。
- 新建完整外框和每行、每列分隔线，使用当前图层的普通 LINE 图元和 ByLayer 颜色；整个操作可按一次 `U` 撤销。

适用于已大致排成行列、位于 WCS XY 平面且同标高的文字。行列识别容差为平均字高的 0.6 倍，最小 0.5；同一单元格识别出多个文字时停止，需先整理。文字外包框高超过 4、锁定图层、标高不同或无法读取外包框时停止，不修改文字。多行文字需要其整体外包框也满足高度条件。

只选择文字；命令不会删除原有表格线，重复运行会叠加新线，不适用于修改已有完整表格。已有表格的自动列宽请用 `ZDWI`。

离线验证：`python tools/check_hzbg_static.py`。使用用户提供的 QW3 的 50 个文字坐标验证实际 LISP 布局函数，结果为 9 行、6 列、4 个空格、总高 45；涵盖选择顺序、最下方表头、重复单元格和坐标平移。未连接或操作 CAD，实际字体外包框刷新和显示效果尚未在 ZWCAD 验证。
