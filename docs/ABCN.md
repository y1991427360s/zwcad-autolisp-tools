# ABCN 四行相序文字

重新加载当前中望项目的 `AA整合版本.lsp` 后，输入 `ABCN`，指定 A 的左中对齐点。

从上到下生成四个独立单行文字 A、B、C、N。使用 HZ 样式、字高 3、宽度系数 0.7，与 T 的结果一致；左中对正，可见左边界对齐、上边界依次相差 5 个图纸单位，与 H 默认排列规则一致。颜色固定为青色（ACI 4），使用当前图层，沿 WCS 向下排列；拾取点由当前 UCS 转为 WCS。

图中必须已有 HZ 样式，否则提示后退出。创建或包围盒读取、移动失败时清理本批文字；一次 U 可撤销整组。取消点选不生成文字。

仅完成静态检查，未连接或操作 CAD；字体显示及实际交互待用户重载验收。AutoCAD 2018 代码未同步。
