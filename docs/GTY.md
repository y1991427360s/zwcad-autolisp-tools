# GTY 电缆文字整理副本

GTY 保留选中的原文字，按原有电缆编号排序与列宽规则整理，再复制到指定位置。

## 使用

1. 预选文字后执行 `GTY`，或执行命令后选择文字。
2. 程序读取文字并完成分行、排序和列宽计算。
3. 点击整理副本的第一行第一列位置。副本按 WCS 水平排列，统一采用指定点的高度；行间距仍为 5。
4. 原文字保留原位，字高、样式、宽度系数、颜色、图层、对齐及扩展数据通过原生 Copy 保留。

取消指定位置不会生成副本；生成中失败会清理本批副本。整个生成过程位于一个撤销组内，一次 `U` 撤销本次生成。

## 检查

```powershell
python tools/check_gty_copy_static.py
python scripts/check_project.py
```

检查执行实际源码表达式，并通过模拟 CAD 接口验证原文字不变、只移动副本、指定点 UCS 转 WCS、目标高度、行列间距、取消和失败清理。未进行 CAD 实测，重新加载整合文件后生效。
