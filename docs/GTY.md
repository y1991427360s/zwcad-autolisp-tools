# GTY 电缆文字整理副本

GTY 保留选中的原文字，按原有电缆编号排序与列宽规则整理，再复制到指定位置。

## 使用

1. 预选文字后执行 `GTY`，或执行命令后选择文字。
2. 程序读取文字并完成分行、排序和列宽计算。
3. 点击整理副本的第一行第一列位置。副本按 WCS 水平排列，统一采用指定点的高度；行间距仍为 5。
4. 原文字保留原位，字高、样式、宽度系数、颜色、图层、对齐及扩展数据通过原生 Copy 保留。

取消指定位置不会生成副本；生成中失败会清理本批副本。整个生成过程位于一个撤销组内，一次 `U` 撤销本次生成。

## GTY2：整理后放到另一张图

在卷册图上整理，直接贴到总图，不用先在卷册图上找地方放副本。

1. 预选文字后执行 `GTY2`，或执行命令后选择文字。分行、排序、列宽和行距 5 与 GTY 相同，`check_gty2_static.py` 逐表达式比对两边。
2. 程序生成排好版的临时副本，用原生 `COPYBASE` 以第一行第一列为基点放进 CAD 剪贴板，再删掉临时副本。原文字不变，图上不留东西，但这张图会显示为已修改。
3. 切到总图按 Ctrl+V，点第一行第一列位置。多个卷册逐张重复，全部贴完后照常在总图再跑一次 `GTY`。

走原生剪贴板而不是导出文本，是因为粘贴会带上文字样式、图层和 AA_LINK，总图的 `SX2`、`SXD` 才认得这些副本。总图里已有同名样式或图层时，以总图的定义为准，和手工 Ctrl+C / Ctrl+V 相同。

粘贴前不要再复制别的东西，否则剪贴板内容会被换掉。关掉卷册图或中望之后是否还能粘贴未验证，建议先贴完再关。

选中的文字在锁定图层上时整批拒绝，本次没有改动，因为这些副本移不动也删不掉。

