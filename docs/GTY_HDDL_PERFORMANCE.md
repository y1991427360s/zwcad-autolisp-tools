# GTY 与 HDDL 性能优化说明

2026-10-13 更新。保持排序、布局和校核规则。GTY 后续改为保留原文字、指定位置输出整理副本，操作见 `GTY.md`。

## GTY

- 超过 128 个文字时先尝试安全分行：按 Y 排序，只有每个相邻带内部的最大 Y 差不超过原容差、带间距大于容差时，才采用快速路径。按原输入序号恢复建行、入行顺序。
- 连锁容差、边界归属等模糊输入沿用原逐项分行。命中后只重建此前经过的行，复用剩余尾链。
- 每行纯 X 排序采用稳定归并。整体带容差的行排序，仅安全分行成功时用归并，其余保留原插入比较次序。
- 分段用倒序累积、一次反转；列宽和移动列坐标按尾链遍历。
- 保留 `acad_strlsort` 和原编号键。排序后的原序号通过平衡树查回行，避免每个编号扫描整张映射表。
- GTY 使用原生 Copy 保留源文字及全部文字属性，仅移动整理副本。普通左基线、默认正 Z 法向且无扩展字典/反应器的副本 TEXT 使用 `entmod` 更新插入点，最后统一 `redraw`。其他对齐、法向或带扩展字典/反应器的对象保留原 COM Move；`entmod` 返回失败或抛出异常时回退到原 COM。目标点与原点完全相同则跳过。

## HDDL

- 安全分行采用同样的带检测，仍保持原来的固定首项代表点和输入次序。模糊输入继续按原规则处理。
- 原分行函数改为命中前缀一次拼接，避免遍历每行时反复复制累计列表。
- 只有行内 Y 跨度不超过 1 时才采用稳定归并，否则保留原插入比较次序并改成迭代，避免递归栈增长。
- 电缆编号通过稳定排序、相邻归组，避免重复 `assoc/subst` 扫描全表。组内成员仍保持原次序。
- 每组只计算一次镜像及共同问题类型。逐行原理号重复仍优先于共同问题，保持此前校核语义。
- 每组同一种共同问题只着色一次；已为目标 ACI 且无真彩色覆盖的实体不重复 `entmod`。
- 原理号顺序不同仍不算问题。问题标记的位置、内容、计数保持一致；按编号处理会改变标记实体的创建先后次序。

## 验证与限制

离线入口：

```powershell
python tools/check_cable_perf_static.py
python scripts/check_project.py
```

性能检查执行实际 LISP 表达式并对照旧版分行、排序和校核逻辑，检查容差链、随机输入、分段、同坐标、非默认法向、不同对齐、失败回退和重复着色。

离线操作计数用于验证重复扫描与列表复制是否减少，不表示 ZWCAD 的实际提速倍数。未连接、加载或操作 CAD；实际耗时需在用户明确授权 CAD 验证后确认。边界模糊的分行保留较慢的兼容路径，优先保证原结果。

下表计数来自实际 LISP AST 的执行，统计逻辑列表遍历和复制。模型不计入 CAD 绘图、COM、字体、Python 自身耗时，也不能用作真实提速倍数。

| 检查样例 | 优化前 | 优化后 | 输出一致性 |
|---|---:|---:|---|
