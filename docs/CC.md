# CC 复制并替换副本文字

入口在根目录 `AA整合版本.lsp`。Windows 剪贴板提供新内容，CAD 中预选的文字提供位置、样式等对象属性。

## 操作

1. 将新文字复制到 Windows 剪贴板。
2. 在 CAD 中预选一个单行文字、多行文字或属性定义，再输入 `CC`。预选依赖 `PICKFIRST=1`。
3. 指定第一个点作为基点。
4. 移动鼠标，由原生 `MOVE` 拖动已经替换为剪贴板内容的副本，指定第二个点放置。对象捕捉、捕捉标记、正交和坐标输入由 CAD 原生命令处理。
5. 支持连续多次放置：放置后继续拖动下一个副本，点击继续放置；按回车、空格或 Esc 退出（按 Esc 取消当前拖动的未确认副本，已放置副本保留）。

支持 `TEXT`、`MTEXT`、`ATTDEF`；不支持块内属性 `ATTRIB`、块参照或多个预选对象。没有预选或剪贴板为空时提示并结束。

`CC` 完整替换副本内容，不保留原文字中的“至”字前缀。`QE` 则修改所选原对象，并保留其已有的前缀规则。

## 实现与边界

先捕获预选集，再读取剪贴板。基点用 `getpoint` 获取；随后 `vla-Copy`、`vla-put-TextString`、`vla-Update` 创建并更新副本，再将副本交给原生 `MOVE`，通过 `command pause` 等待目标点。

不再用 `grread`、逐帧 COM 移动或手写 `osnap` 模拟拖动。基点通过 `_non` 传给原生命令，避免已选基点被二次捕捉。副本从创建到放置都处于同一撤销组中。

原生 MOVE 开始等待目标点前，用 `redraw` 模式 2 隐藏副本在原位的静态显示，保留鼠标位置的原生拖动图像；放置后用模式 1 恢复副本显示。原始文字不隐藏，也不修改副本的 Visible 属性或 DXF 60，避免拖动图像一同消失。取消时沿用删除副本和刷新显示的清理逻辑。此显示调整尚未在 CAD 中实测。

拖动期间临时设置 `DRAGMODE=2`，保证启用原生拖动显示；正常完成、Esc 或错误退出都恢复原值。命令不改写 `OSMODE`，保留用户的捕捉开关。错误处理删除尚未确认的副本并刷新显示，再关闭撤销组、恢复命令回显。

支持连续多次复制模式。每次指定目标点后立即放置该副本，并自动进入下一个副本的拖动；回车或空格时检测未拾取新目标点，删除本次多余副本并退出；Esc 则由错误处理删除当前未放置副本并退出。整批放置对象包含在同一个撤销组中，按一次 U 可整体撤销。多行文字行内格式随完整内容替换而改变，对象级样式由副本保留。

## 静态检查

在项目根目录运行：

```powershell
python tools/check_all_static.py
python gen_命令索引.py --check
```

专项检查覆盖顶层定义、调用参数数量、先替换再启动原生拖动的顺序、原生交互输入、取消清理、预览设置恢复，以及 UTF-8 无 BOM / CRLF。

本次只做静态验证。实际鼠标跟随、捕捉标记、中文显示、放置、Esc 清理和一次 U 整体撤销仍需在 ZWCAD 2026 实机验收；静态通过不代表这些交互已实测通过。未经用户明确要求，不连接 CAD、重新加载或创建测试图。
