# CC 复制并替换副本文字

入口在根目录 `AA整合版本.lsp`。Windows 剪贴板提供新内容，CAD 中预选的文字提供位置、样式等对象属性。

## 操作

1. 将新文字复制到 Windows 剪贴板。
2. 在 CAD 中预选一个单行文字、多行文字或属性定义，再输入 `CC`。预选依赖 `PICKFIRST=1`。
3. 指定第一个点作为基点。此时会立刻创建副本，并把副本内容换成剪贴板文字（叠在原文字上）。
4. 移动鼠标：副本会像原生 `CO` 一样跟着光标移动，看到的就是新文字本身。点击放置，或按回车用当前点；按 Esc 取消并删除副本。
5. 原对象和剪贴板保持不变。

支持 `TEXT`、`MTEXT`、`ATTDEF`；不支持块内属性 `ATTRIB`、块参照或多个预选对象。没有预选或剪贴板为空时提示并结束。

`CC` 完整替换副本内容，不保留原文字中的“至”字前缀。`QE` 则修改所选原对象，并保留其已有的前缀规则。

## 实现与边界

先捕获预选集，再读取剪贴板。基点用 `getpoint`；随后 `vla-Copy` + `vla-put-TextString` 生成真实预览实体，第二点用 `grread` 跟踪鼠标，用 `vla-Move` 按增量拖动该副本。COM 坐标按 `(trans pt 1 0)` 以 WCS 传入。

拖动过程中显示的是完整对象（含新文字），不是临时矢量框。确认后保留副本；Esc、其它未知输入或错误会删除该副本。不提供连续多次复制模式。

多行文字的行内格式随完整内容替换而改变，对象级样式随副本保留。

命令使用项目撤销框架。基点取消前不会创建副本；副本创建后的取消或失败会删除副本，再调用公共错误处理器结束撤销组。删除失败的异常被捕获，不保证故障状态下绝无残留；必要时用 `U` 撤销本轮。

## 静态检查

在项目根目录运行：

```powershell
python tools/check_cc_static.py
python tools/check_fdx_static.py
python gen_命令索引.py --check
```

`check_cc_static.py` 依赖同目录 `check_fdx_static.py` 的表达式解析器；两份脚本需一起保留。检查覆盖整文件列表解析、唯一顶层 CC 定义、预选、剪贴板替换、`cc:move-ucs` / `cc:drag-object` 真实副本拖动、取消与错误清理，以及 UTF-8 无 BOM / CRLF。

截至 2026-09-12，预览方式为真实副本拖动（基点后立刻替换文字，拖动时移动该实体）。没有连接 CAD 验证；实际加载、拖动显示、放置、取消和一次 U 整组撤销仍待实机验收。

报“输入的列表有缺陷”时，先核对实际 load 路径与当前工作文件，运行上述检查；不能把编码检查或索引生成成功当作加载成功。未经用户明确要求，不得自动连接 CAD、重新加载或创建测试图。
