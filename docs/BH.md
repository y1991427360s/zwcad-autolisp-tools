# 电缆编号命令使用说明（BH1 / BH2 / BH3 / BHG）

这组命令给 `ZDDL` 生成的电缆统一编号，把电缆线上方的“未编号”换成正式编号（如 `1B-103`）。
一根电缆在两端柜子的端子排上各出现一次，两端编号必须一样。编过的号会记下来，到另一端编号时直接填上同一个号，两端都已编号的顺便核对。

| 命令 | 用途 |
|---|---|
| `BH1` | **编号**：依次点选电缆线，按点选顺序分配新编号，可撤销本批 |
| `BH2` | **记录与填写**：框选整个柜，把已编号但没记录的电缆记进记录，给有记录的“未编号”按记录填写；不分配新编号 |
| `BH3` | **从电缆清册表格记录**：框选清册文字，以清册为准写入记录（没有的记入，有的强制改成清册编号） |
| `BHG` | 以图为准改记录（编号或柜名改过之后用） |

## BH1：依次点选编号

1. 先保存图纸（编号记录写在 dwg 所在文件夹，从未保存的新图没有文件夹）。
2. 输入 `BH1`，**点选起点柜名大字**（字高 ≥80；点到小字会提示重选）。
3. 输入“-”前面的部分，如 `1B`（回车沿用上次）；再输入起始号，如 `101`、`131`、`132` 或其他数字。输入几位数就按几位数往后排，`01` 会排成 `DS-01`、`DS-02`。
   - 如果记录里**本柜已经有这个前缀的编号**（例如以前编过、后来在图上按 U 撤回了，但记录还在），会问 `[沿用(K)/重新编号(R)] <沿用>`：
     - 沿用：点到这些电缆时直接填记录里的号（命令行显示“按记录填入”），不占顺序号。
     - 重新编号：清掉本柜、本前缀的这些记录，从你输入的起始号重新编；图上显示旧号的线点到后也会重新编号。被替换的旧号记进“旧编号”列，另一端如果已经填了旧号，到那边跑 BH1 或 BH2 会自动改成新号。别的柜登记的编号（其他前缀）不受影响。
4. **依次点选要编号的电缆线**：按你想要的编号顺序一根一根点，点过的线会高亮。点错了输入 `U` 去掉最后一根；同一根点两次会提示“已经选过”。提示里显示已选根数和下一个顺序号。
5. **回车开始编号**：程序先缩放到所有选中的电缆线，找出芯线；再缩放到连同芯线另一端的原理号区域都在屏幕内，用屏幕内查询一次识别完（和 BH2、XYG 一样快），然后恢复你原来的视图。接着**按点选顺序**编号，命令行逐根显示结果，例如 `第 1 根 至主变测控柜1：新编号 1B-101`。
   - 新的终点柜按点选先后依次取号：101、102、103……
   - 同一个终点柜**第二次**出现时，第一根自动改成 `101A`，这一根编 `101B`；第三根 `101C`，以此类推（跨批也一样）。
   - 信号线到录波柜固定 `130`、到公用测控柜固定 `131`，不占顺序号；多根时同样是第一根改 `130A`，之后 `130B`、`130C`。
   - 记录里已经有这根电缆（另一端编过）：直接填同一个号，不占顺序号。
   - 已经有编号的电缆：只和记录核对，不占顺序号。一致就不动；是旧编号就改成新编号；冲突就标红，并在电缆线右端写原因。
   - 顺序号排到 130 或 131 时会问你跳过还是照常使用；记录里同前缀已经用过的号会自动跳过。
   - 线上方没有“至…”的绿色直线不是电缆，提示后跳过。
   - 个别线在屏幕内没认出原理号（例如原理号离得特别远）时，这一根会自动改用全图查询再识别一次。
6. 一批编完后提示 `[撤销本批(U)] <继续点选>`：输入 `U` 撤销整批（文字、颜色、原因标记和记录一起恢复，顺序号退回）；回车继续点下一批，顺序号接着往下排。
7. 不点任何线直接回车（或 Esc）结束。

命令行在每批结束时显示“识别 x 秒，编号 y 秒”。如果一次选的线分布得很散，缩放后的范围会很大，文字在屏幕上很小；一般按一个柜、一片端子排为一批比较合适。

每编一根都会先写记录文件，写成功后才改图，所以中途 Esc 也不会丢已编的号。命令结束后再按一次 `U`，会撤销本次命令的全部图面修改，但不会撤销已写入的记录。

## BH2：记录与填写（不分配新编号）

适合两种情况：电缆编号是以前手工写的、记录里还没有；或者电缆另一端已经编过号，这一端还是“未编号”。

1. 输入 `BH2`，**框选一个起点柜**：柜名大字、绿色电缆线、芯线、原理号和电缆文字都要框进去，和 `XYG` 一样（需要在视口内）。框选范围内最左边的大字就是起点柜名；没框到大字时会让你点选柜名文字。
   - 只点选了几个对象也可以（例如柜名大字和几根电缆线）：选择集里找不到“至…”或它左边的编号时，会到图上补查这根线上方的文字（在屏幕内用快速查询，不在屏幕内用全图查询）。
2. 不问前缀和起始号，直接处理（规则见下文“每根电缆怎么处理”）：
   - 已编号、记录里没有 → 记入记录；
   - “未编号”、记录里有（另一端编过）→ 按记录填写；
   - “未编号”、记录里也没有 → **不动**，命令行统计“未编号且没有记录 N 根”，需要编号时用 `BH1`；
     - 其中两端柜名相同、原理号只差末尾 I/II 后缀（如图上 `A610 B610 C610 N600`、记录 `A610I B610I C610I N600`）的，算**疑似记录**：仍不填，选中这根电缆的编号，在电缆线右端写红字，例如 `[疑似 YYH-136] 原理号不一致，无法填入：图上 A610 B610 C610，记录 A610I B610I C610I（记录所在图纸）；统一两张图的原理号后再运行 BH2`。疑似有多根（如 I、II 两根）时全部列出。I/II 常用来区分两根不同电缆，所以只提示、不自动填。
   - 已编号的和记录核对：一致不动；是旧编号就改成新编号；冲突标红写原因。
3. 完成后命令行报告各类数量和记录文件路径。冲突和无法识别的电缆会被**选中**，同时在电缆线右端写上红色原因。

### 终点是“相邻屏柜”的环网电源线

用 LNZ/LNY 画、ZDDL 出线后写着“至相邻屏柜”的环网电源线，BH2 会按记录（一般是 BH3 从 HWD 环网清单登记的）找出实际相邻的柜，填上编号，并把“至相邻屏柜”改成“至实际柜名”：

- 同一原理号（如 L1 N1）的“相邻屏柜”电缆为一组，在记录里找一端是本柜、原理号相同的电缆（**不看记录里谁是柜名1、谁是柜名2**：这些记录常是两边各自用 BH1/BH2 记的，方向不可靠）。
- 一组两根时，记录也应正好两根，先分出前一个柜和后一个柜：
  - 编号“-”前相同（如 SML-22、SML-23）时按顺序号，**小的是前一个柜**，环网电缆是沿链连续编号的；
  - 编号无法比较（如“***”）时才看记录方向：本柜作柜名2 的是前一个柜，作柜名1 的是后一个柜。
- 再按引线长短配对：**离端子排近（引线短）的配前一个柜**，**离端子排远（引线长）的配后一个柜**。
  - 向下引线：上面一根是前一个柜，下面一根是后一个柜；
  - 向上引线：下面一根是前一个柜，上面一根是后一个柜。
- 一组只有一根时：记录里只有一根（链头、链尾）就用它；有两根则无法确定。
- 无法确定的情况（只有一根但记录有两根、两根但记录不是正好两根、两根记录分不出前后、记录里没有、同一组超过两根），保留“至相邻屏柜”和“未编号”，选中并在命令行说明原因。
- 改成实际柜名后，以后 BH2、BHG、HDDL 都能直接按柜名对上号。
- **柜名必须和环网清单一致**：端子排上的柜名大字要和 HWD 清单里的柜名一字不差（空格除外）。例如图上是“风功率预测柜”、清单写“风功率预测系统柜”，就找不到前后柜，两根都会提示“记录里没有本柜的相邻屏柜电缆”。

### 合画柜：两张图合画成一张（柜名写成“1(2)#”）（2026-10-26 起）

1#、2# 两个柜接线相同时常合画成一张图，柜名大字写成 `35kV 1(2)#SVG控制柜`，而电缆另一端（如同步时钟主机柜）是分开登记的两根：`DS-24`（至 35kV 1#SVG控制柜）、`DS-25`（至 35kV 2#SVG控制柜）。BH2 会把合画的写法拆开分别查记录，再合成一个编号填上：

- 认的写法：数字后面括号里写另一张图的数字，如 `1(2)#`、`1（2）#`（全角括号也认），括号里多个用逗号、顿号或 `/` 分开（`1(2,3)#`）。起点柜名、“至…”终点柜名、原理号里都可以有，个数要一致；只出现在一处时另外两样两张图通用。原理号如 `1(2)UBY-901` 拆成 `1UBY-901`、`2UBY-901`；数字带相同字母尾缀的连尾缀一起换，如 `A630I(640I)` 拆成 `A630I`、`A640I`（括号里外尾缀必须相同）。
- **“未编号”**：先按原样查记录（记录里本来就写着合并柜名的，如 `1(2)#35kV母线保护柜`，照常直接填）；查不到再拆开：
  - 各张图都有记录 → 合成编号填入：只差一段数字时写成 `DS-24(25)`、`1(2)UBY-105`；编号完全一样就写一个。计入“按记录填入”，结果卡片另有一行说明合画柜填入几根。
  - 只有部分有记录 → 不填，选中并在电缆线右端写 `[合画柜] 合画柜只找到部分记录：35kV 1#SVG控制柜—同步时钟主机柜 记录 DS-24；35kV 2#SVG控制柜—同步时钟主机柜 没有记录；…`，另一张图编号记录后再跑 BH2。
  - 记录编号差了不止一段数字（如 `1B-101A`、`1B-101B`）合不成 → 不填，选中写原因，请手工填写。
  - 都没有记录 → 和普通电缆一样算“未编号且没有记录”。
- **已编号且编号也是合并写法**（如 `DS-24(25)`）：拆开逐张核对——都一致不动；没记录的分别记入（记两条：`DS-24 35kV 1#SVG控制柜…`、`DS-25 35kV 2#SVG控制柜…`）；某一张是旧编号的改成新编号后重新合成；某一张编号冲突则标红写原因（注明是哪一张）。
- **反方向：记录是在合画图那端记的**（如 `1(2)ZYB-103  35kV 1(2)#站用变进线柜 — 35kV故障录波柜  1(2)ZYB-A421 …`），这一端（故障录波柜）是分开画的两根：BH2 把这条记录的柜名、原理号、编号按同样个数拆开（`35kV 1#站用变进线柜 … 1ZYB-A421 … → 1ZYB-103`，`2#` 同理）。“未编号”的按拆开的编号填入；已编号的和拆开的编号核对，一致不另记，不一致标红写“与合画图记录 1(2)ZYB-103 拆开后的编号 2ZYB-103 不一致”。编号拆不开（如 `UTB-101B` 至 `1(2)#35kV母线保护柜`）的记录不参与。
- 合画柜的编号用 BH1 分配时不会拆开（BH1 照旧按合并柜名编一个号），请在分开的那一端先编号，再到合画图上跑 BH2。

## 命令行输出与结果卡片（2026-10-25 起）

`BH1`（每批一次）、`BH2`、`BHG`、`BH3` 和 `JM` 的命令行只留一行汇总，例如 `[BH2] 完成：填入 1，冲突 1；1 条问题已选中，明细见结果卡片`。逐根的冲突、疑似、无法编号、说明等明细和完整统计写进 `%TEMP%\AA-CAD-Report\report.txt`，由 AutoHotkey 面板（`excel-command-panel`）弹出“CAD 结果”卡片显示，点条目会在 CAD 空闲时缩放到对象并选中。图上的红字原因和选中照旧。

- 结果文件写不进去时，明细照旧逐条打在命令行，信息不会丢。
- 没有开 AHK 面板时只有命令行一行汇总和图上红字；需要明细时打开面板脚本即可（之后的命令会弹卡片）。
- LISP 端共用函数：`aa:rep-begin`、`aa:rep-item`、`aa:rep-info`、`aa:rep-end`、`aa:rep-zoom`（见 `AA整合版本.lsp` 的“AA 结果卡片”段）。

## BH3：从电缆清册表格记录

适合把已经整理好的电缆清册（如电源线手拉手清单）一次登记进记录。

1. 输入 `BH3`，框选清册文字。每行的列顺序为：**起点柜、电缆编号、终点柜、规格、芯数、原理号 1、原理号 2……**（和 YSDL/HDDL 的清册格式一致，如 `通讯线 2 B+ B-`、`4×2.5 4 101 103`；也认“芯数、规格”的旧顺序）。分行方式和 HDDL 一样：按高度归行，行内按左右排序。
   - 芯数按一两位数字识别（三位以上数字如 `101` 是原理号）。规格列可以空着（第 4 个文字就是芯数 `2`，后面直接是 `B+ B-`）：这时第 5 个文字当作原理号，命令行汇总一行提醒“N 行没写规格”（列出前 8 个编号），并选中这些编号，请在清册补写规格。
2. **以本次选中的清册为准**写入记录，不会因为冲突或重复拒绝登记，有疑问的照样记入并在命令行逐条“说明”、选中这些编号：
   - 记录里没有这根电缆：记入；
   - 记录里有、编号不同：**强制改成清册上的编号**，原编号存进“旧编号”列（同 BHG），端子排图上还是旧编号的，运行 BH1 或 BH2 会自动改成新编号；
   - 清册上只改了一端柜名或原理号的同一根电缆（编号相同）：把记录换成清册内容（同 BHG）；
   - 编号属于另一根电缆（两端柜名和原理号都对不上）：**删掉那条记录**，编号按清册给这根电缆，说明“原属 A—B 的记录已删除，按清册改给 C—D”；
   - 清册里同一起终点、原理号有两根（编号不同），或同一个编号写给了两根电缆：**两根都记入**，说明里提醒核对（同一起终点、原理号的两根，BH2 对号时只认前一根）；
   - 清册里完全相同的两行（柜名、原理号、编号都一样）：只记一次；
   - 和记录一致：不动。
3. 编号是“***”这类占位编号的行照常记录，**占位编号可以多根电缆共用**，不算重复。
4. 编号为空或“未编号”、柜名不全、没有原理号的行（包括表头）跳过，命令行统计行数。
5. 先写记录文件，写成功后才选中有说明的编号；上一版标红的编号会恢复白色。重跑时已经一致的行（包括清册内重复的）不会重复记录。

> 原理号要写在清册里，BH3 才能和端子排上的电缆按“两端柜名 + 原理号”对上号。

## 怎么认出“同一根电缆”

每根绿色电缆线读取三样东西：

| 内容 | 从哪里读 |
|---|---|
| 起点柜 | 框选范围内最左边的柜名大字 |
| 终点柜 | 电缆线上方的“至XXX”，去掉“至” |
| 原理号 | 和 `JM` 一样：电缆线 → 竖向芯线 → 端子排上的竖排原理号 |
| 电缆编号 | “至XXX”左边最近的那个文字（ZDDL 写的“未编号”或已有编号） |

**两端柜名（不分哪端是起点）+ 原理号集合（不分顺序）**相同，就是同一根电缆。比较时柜名去掉空格、忽略大小写，原理号去掉空格、转成大写。

> 所以两端的柜名必须写得一致：A 柜图里的大字“1号主变保护柜”，要和 B 柜图里的“至1号主变保护柜”对上（空格不影响）。写成“1#主变保护柜”就对不上，会被当成另一根电缆，重新分一个号。

## 每根电缆怎么处理

| 情况 | 处理 |
|---|---|
| 已有编号，记录里没有这根电缆 | 记入记录 |
| 已有编号，和记录一致 | 不改；之前因冲突标红的恢复成白色 |
| 已有编号，是记录里的旧编号（另一端用 `BHG` 改过） | 自动改成记录的新编号，命令行统计“旧编号改为新编号” |
| 已有编号，和记录不一致（也不是旧编号） | 编号标红，右端写“[编号冲突] 与另一端记录编号 X 不一致” |
| 已有编号，但这个编号记录里已经属于另一根电缆（“***”等占位编号除外，可多根共用） | 编号标红，右端写“[编号冲突] 编号已被另一根电缆使用（柜A—柜B）” |
| “未编号”，记录里有这根电缆 | 直接填入记录的编号（另一端编过的号） |
| “未编号”，记录里没有 | BH1：分配新编号并记入；BH2：不动，只统计数量 |
| 本次框选里出现两根完全相同的电缆 | 后一根标红，写“本次选择中同一起终点、原理号的电缆重复” |
| 电缆线上方没有“至…”去向文字 | 不是电缆（只是绿色水平线），直接跳过：不标记、不选中，命令行只报跳过的根数；BHG 同样处理 |
| 找不到编号文字、终点柜名是“未填写”、芯线没找到原理号 | 不编号，右端写“[无法编号] 原因”并选中 |

每次运行前，先删掉这些电缆线右端上一次写的原因文字（`BH_MARK` 图层），所以改正后重跑就会清掉旧提示。

## 新编号规则（BH1）

格式固定为 `前缀-号码[字母]`，例如 `1B-103`、`2B-104A`。

1. **一个终点柜一个号**，按点选顺序，第一次出现的终点柜先编。例如起始号 101：至主变测控柜1 → 101，至主变测控柜2 → 102，至主变保护柜1 → 103。
2. **同一终点柜再次出现**：第一根改成 `101A`，之后 `101B`、`101C`……只有 1 根时不加字母。
3. **专用号**（只看原理号全部是信号线 5xx/7xx/9xx 的电缆，判断规则同 `JM`）：
   - 终点柜名含“录波”（如主变及110kV故障录波柜、35kV故障录波柜）→ 固定 `130`，多根时 `130A`、`130B`、`130C`；
   - 终点柜名含“公用测控” → 固定 `131`，多根时同样加字母。
   - 到这些柜的非信号线电缆（如 +KM/-KM）不用专用号，照常按顺序编。
4. **避开已用号**：同一前缀在记录里已经用过的号（不管带不带字母，包括“旧编号”列里的号）会跳过。
5. **顺序号排到 130 或 131**：会停下来问 `[跳过(S)/照常使用(U)] <跳过>`，由你决定。
6. 专用号已经被同前缀的其他电缆用过时，新电缆从字母开始编，并在命令行提示人工确认。

## 记录文件

- 位置：dwg 所在文件夹下的 `电缆编号记录.txt`。**同一个文件夹里的各卷册图共用这一份**，所以一根电缆两端在不同卷册图里也能对上号——请把同一工程的卷册图放在同一个文件夹。
- 格式：UTF-8 文本，TAB 分隔，第一行是表头：`电缆编号 柜名1 柜名2 原理号 图纸 时间 旧编号`。
  - “原理号”一列是这根电缆的全部原理号，按文字排序、空格分隔；“图纸”是编号时所在的 dwg 文件名；“旧编号”是被 `BHG` 替换掉的编号（按时间先后，空格分隔，一般为空）。
  - 记事本里 TAB 宽度不固定，列看起来会错位；用 Excel 打开就能按列对齐查看。
  - 只有 6 列的旧版记录文件照常读取，下次写入时自动补上“旧编号”列。
- 顺序：BH1 **先写记录文件，写成功了才改图**。文件被占用或没有写权限时弹窗提示，图纸不动。
- 撤销：`U` 只撤销图面。如果撤销了，记录里仍保留这些编号；下次再运行 BH1，同一根电缆会直接填回同一个号，不会乱。
- 编号编错了：用下面的 `BHG` 改记录，不需要手工编辑文件。
- 记录里同一根电缆有多行时，以最前面一行为准。

## BHG：以图为准改记录

第一次编号后发现编错了，记录里已经存了错号，之后 BH1 会一直报“与另一端记录编号不一致”。这时：

1. 在图上把编号改成正确的（可以只改一端）。
2. 运行 `BHG`，框选方式和 BH2 一样（起点柜大字 + 要改的电缆）。
3. 每根电缆的处理：

| 情况 | 处理 |
|---|---|
| 图上编号和记录不同 | 记录里的编号改成图上的编号，原编号存进“旧编号”列；之前的红色标记清掉、文字恢复白色 |
| 图上编号记录里没有这根电缆 | 记入记录 |
| 图上是“未编号” | 没有编号可核对，**不参与重复检查**（例如两根“至相邻屏柜”的同原理号环网线）；记录里有这根电缆就删除（之后 BH1 会当作新电缆重新编号），图上不动，上次误标的红色和原因文字清掉 |
| 图上编号在记录里属于“只改了一样”的电缆：原理号相同、两端柜名有一个相同（起点柜或终点柜改了名），或两端柜名相同、只改了原理号 | 判定为同一根电缆：把那条记录换成图上的柜名和原理号，编号不变（例如把“至相邻屏柜”改成“至公用测控柜”，或把柜名大字“有功智能控制柜”改成“智能有功控制装置柜”） |
| 图上编号属于另一根电缆，而那根电缆**也在本次框选里**，并且图上已改用别的编号或改成“未编号”（两根互换编号、把编号挪给另一根） | 两条记录都按图改，各自的原编号存进“旧编号”；另一端再跑 BH1/BH2 会自动跟改。那根电缆图上仍是这个编号、编号冲突或无法识别时，撤回改动，按冲突标红并写“…，那根电缆本次没有改用别的编号” |
| 图上编号属于另一根电缆（另一端柜名和原理号都不同），那根电缆不在本次框选里 | 不改记录，编号标红写原因并选中 |
| 本次框选里两根电缆写了同一个编号 | 后一根标红，写“本次选择中编号重复” |
| 和记录一致 | 不改，红色恢复白色 |

4. 到电缆**另一端**运行 `BH1`：那边如果还是旧编号，会自动改成新编号，不再报冲突。

**柜子改名时**：先在这个柜的图上改柜名大字，对整个柜运行一次 BHG，这个柜的全部电缆记录都会换成新柜名；再把其他柜图上“至旧柜名”的文字改成新柜名，对端再跑 BH1 就能对上号。

BH1 报冲突时，命令行最后会提示：如果是图上改过编号、终点柜名或原理号，确认图面正确后运行 BHG。

BHG 同样先写记录文件再改图；`U` 只撤销图面上的颜色和标记，记录里的修改不会撤销（需要时再跑一次 BHG 改回来）。

## 和其他命令的关系

- 上游：`ZDDL` 在电缆线上写“未编号”“至XXX”“未填写”；BH1 / BH2 依赖“未编号”和“至XXX”的位置（电缆线上方、“至”左侧约 20）。
- `JM` 填截面不影响编号，先后都可以。
- 如果端子排原件已经用 `SX` 标记过，BH1 / BH2 改的是原件里的编号文字，之后执行 `SX1` 就能把编号刷新到草稿、XYG、GTY 副本里。
- 编号改了会影响排序，`SX1` 之后重跑一次 `GTY`。
- 汇总后仍用 `HDDL` 做最终核对。

## 速度（2026-10-24 优化，BH2 框选与 BHG）

旧做法每根电缆线要做两次窗口查询：一次找“未编号”“至…”，一次清旧原因文字。查不到东西时，窗口查询会退回扫描整张图，而右端通常没有旧标记，所以几乎每根线都要扫一遍全图。现在改为：

- 框选集里的文字只读一次，按高度排好；电缆线从上到下处理，顺着这份列表扫一遍。文字没被框进选择集时（找不到“至…”），才在当前视图内补查一次，不再扫全图。
- 旧原因文字（`BH_MARK`）整个命令只查一次，再按坐标对应到各根线。
- 记录文件里每条记录的“柜名 + 原理号”键只算一次。
- 芯线和原理号的识别仍用 XY 的原逻辑，没有改动，结果和原来一致。
- 命令结束时会显示“用时 N 秒”，方便对比。
