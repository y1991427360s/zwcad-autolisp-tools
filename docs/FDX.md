# FDX 连续分配文字

`FDX` 位于根目录 `AA整合版本.lsp`，将连续选择的文字批次依次移动到目标方框，并自动复用 `DX` 排列。

## 操作

1. 选中全部目标方框后输入 `FDX`；也可以先运行命令，再选择方框。
2. 排序默认 `R`：从上到下，同排从左到右。`C`：从左到右，同列从上到下。不是按点选次序分配。
3. 临时绿线标出当前方框。选择一批文字，按空格或回车确认。
4. 本批整体移入当前方框，自动按 DX 规则排列，成功后进入下一框。
5. 重复选字、空格；处理完全部方框后结束，也可空选回车或按 `Esc` 提前结束。

提前结束保留已完成批次。命令退出后，一次 `U` 撤销本轮修改。

## 识别与排列

- 方框支持四角闭合的二维 `LWPOLYLINE/POLYLINE`，以及所选完整水平、竖直 `LINE` 围成的矩形；弧边和块内方框不支持。
- 方框识别和排序使用当前 UCS，仅识别与其坐标轴平行的矩形；直线框仅使用选中的边线，不扫描全图。
- 文字仅处理本批选中的 `TEXT/MTEXT`，不会把方框中已有文字自动加入本批。
- DX 与 FDX 共用排列规则：不含汉字的白色文字为端子号，不含汉字的青色文字为原理号。两列分别按文字包围盒中心从上往下排序，第一个白色与第一个青色配对，第二个与第二个配对，依此类推，不要求原来处于同一高度。数量不等时，多出的文字继续排列在末尾，另一列留空。
- 白色、青色中含汉字的文字单独作为终点柜名称，不占配对序号；按原位置从上往下排序后，在两列右侧、最后一行高度从左往右排列。
- 颜色判断支持随层颜色、ACI 白色 7 / 青色 4，以及接近纯白、纯青的真彩色；蓝色不参与排列。
- 其他颜色文字随整组移动，但不参与 DX 排列，命令会提示数量。字号不自动缩小。
- DX 仍按 WCS 水平排列；常规操作使用世界 UCS。斜 UCS 下的旋转框排列不能视为已验证支持。

## 失败与撤销

选中锁层文字或无法读取包围盒时，整批不移动。移动、排列失败或空间不足时，尝试将本批所有文字恢复到移动前的位置，方框序号不前进。若提示恢复失败，应结束命令后用 `U` 撤销本轮。

`fdx:place` 保存本批实体数据并负责恢复；`fdx:arrange` 将已知目标框转换为 DX 分组记录，调用 `dx:apply-group`，不运行交互式 `c:DX`，不要求再次选择，也不另开撤销组。

## 验证状态

截至 2026-09-06，最终 FDX 自动接 DX 的版本仅完成离线检查，未完成原生 CAD 实机验收。用户报告的 `类型不正确 - -1119.71` 已定位为误用 `(car (last pts))`，FDX 内同类写法已修复；离线预览回归覆盖负坐标和非零标高。

```powershell
python tools/check_fdx_static.py
python gen_命令索引.py
python gen_命令索引.py --check
```

这些检查验证源码结构、参数数量、局部赋值、预览点结构及编码和索引，不证明真实 CAD 的移动、字体显示、排列或撤销行为正确。只有用户明确要求后，才可操作 CAD 验证。
