# 命令别名设置面板

双击项目根目录的 **命令别名设置.cmd**，即可打开独立设置窗口。需要本机 Python 3.10+（含 tkinter），无需安装第三方包，不连接 CAD。

## 它解决什么问题

中望 CAD 的命令行别名（输 `C` 回车等于 `COPY`）保存在本机 `%AppData%\ZWSOFT\ZWCAD\2026\zh-CN\Support\ZWCAD.pgp`，**不在同步目录里**。多台电脑之间不会自动同步；中望升级或重置配置时 PGP 可能被覆盖，手工别名会丢。

本面板采用“主表 + 应用”两层结构：

1. **别名主表（唯一可信来源）**：`config/aliases.csv`，随同步目录走，UTF-8 带 BOM、CRLF。列为 `别名,目标命令,备注,标记`，一个命令可对应多条别名。旧的三列主表可直接读取，保存时自动升级为四列。
2. **面板**：编辑的是主表；保存时先写主表，再把主表“应用”到本机 PGP。
3. **换电脑**：打开面板若提示“与本机 PGP 不一致”，点“仅应用到本机”即可把主表同步到本机。

## 首次运行

面板打开时会自动扫描本机 PGP 末尾用户手工添加的自定义别名（例如 `C→COPY`、`CI→CIRCLE`、`R→ROTATE`、`Q→QSTXT`），导入主表并在界面上列出导入了哪些；中望默认自带的别名不导入。被注释掉的行（例如 `; F, *FIND`）保持原样，不会动。

## 界面说明

- **左侧**：命令列表。自动扫描 `AA整合版本.lsp`、`V6/` 下全部 `defun c:XXX`，以及 `V6/` 下 C# 插件的 `[CommandMethod("XXX")]`（例如 `DWGWIN`），带功能说明；并列出主表里指向中望原生命令的条目（标记为“原生”）。
- **搜索**：按命令名、别名或功能说明模糊匹配；可勾选“未设别名”或“与本机不一致”过滤。
- **右侧**：当前命令的别名编辑区。每行一条，可增、删、改；备注可选；原生命令条目带“原生”徽标。
- **行底色**：白色=与本机一致；黄色=与本机 PGP 不一致；浅灰=尚未设别名。
- **重新扫描命令**：新增 LISP/C# 命令后不必关闭面板，点此刷新列表；当前编辑内容会保留。

## 命令说明的来源

命令名、文件、行号和功能说明统一由 `gen_命令索引.py` 扫描，面板不再单独解析，两边结果必须完全一致。说明来源依次为：命令定义上方的 `;;; 功能:` 注释头、文件开头 `;;; - 命令: 说明` 清单、AICAD 与 C# 的默认说明字典。新增命令必须写 `;;; 功能: 一句话说明`，否则 `python gen_命令索引.py --check` 和 `python tools/check_alias_panel_static.py` 都会失败并列出缺失命令。

## 按钮

- **保存并应用到本机**：先写主表，再事务式应用到本机 PGP。保存前会自动备份主表和 PGP 到 `backups/alias-panel-<时间戳>/`，失败自动回滚。
- **仅应用到本机**：丢弃当前未保存的编辑，把主表已有内容同步到本机 PGP。适合换电脑或 PGP 被重置后使用。
- **从本机 PGP 重新导入**：仅当本机 PGP 还没有托管区块时可用，用于在新机器上重建主表。
- **重新扫描命令**：重新扫描当前插件命令与历史备份命令，不改变主表内容。
- **打开备份文件夹**：打开 `backups/`。

## 原生命令标记

通过“添加原生命令别名…”登记的条目，主表第四列写入 `native` 标记。目标命令即使无法离线核对（例如 `MATCHPROPX`），保存时也只警告不拦截；主表重新读取后标记仍然保留。普通条目目标未知时仍会硬拦截。

## 冲突校验（保存时强制）

以下情况**禁止保存**：

- 同一别名指向两个命令；
- 别名与任何插件命令名相同（会让原命令无法输入）；
- 别名为空或含字母、数字、`-` 之外的字符；
- 目标命令既不是插件命令，也没在本机 PGP 出现过，且没有 `native` 标记（原生命令请先用“添加原生命令别名”登记）。

以下情况**只警告**，允许继续：

- 别名与中望默认 PGP 已有条目撞名（例如把 `C` 改指向别的命令），会提示原来指向什么；
- 首次应用时，用户区已有的自定义别名将被迁入托管区块；
- 主表别名指向的插件命令只出现在 `backups/` 历史版本中、当前源码已没有（例如 `Q→QSTXT`），提示“该插件命令可能已删除或改名”；
- 带 `native` 标记的条目目标无法离线核对。

## PGP 写回规则（安全保证）

- **编码不写死**：先按 utf-8-sig → utf-8 → GBK 顺序检测，能无损往返才判定；写回时用原编码、保持 CRLF。
- **托管区块**：面板只重写 PGP 末尾由 `; ===== BEGIN/END ZW-auto_lisp aliases =====` 圈出的区块；区块之外的中望默认条目和注释一律不动。
- **默认别名只注释不删除**：主表里的别名若在默认区已有同名条目，原行前加 `; ` 并标注“已由面板覆盖”，绝不删除。
- **删除别名后自动还原**：如果从主表删掉某别名，下次应用时区块外带“已由面板覆盖”标记的默认行会逐字节恢复原样，并在确认弹窗里列出“将恢复中望默认别名”。
- **备注不写行尾**：托管区块内每条别名只写 `别名, *命令`；备注写在上一行独立的 `; 备注`，避免中望解析器不支持行尾注释。旧格式（行尾带备注）仍可读取，再次保存时自动升级。
- **事务**：写入前先把主表和 PGP 字节级备份到 `backups/alias-panel-<时间戳>/`；写临时文件→回读校验→原子替换；任何一步失败按实际阶段恢复并提示。

## 生效方式（面板不碰 CAD）

保存成功后，到中望 CAD 命令行输入 `REINIT`，勾选“PGP 文件”后确定；若无效请重启 CAD。**插件命令的别名要等 LSP 加载完成后才能用。**

## 多台电脑

主表随 Syncthing 同步；PGP 是本机文件。换电脑或 PGP 被重置后：

1. 打开面板，界面会提示“与本机 PGP 不一致”；
2. 点“仅应用到本机”；
3. 若本机用户区存在主表没有的别名，弹窗会逐条列出，可选择“并入主表”或“保持原样留在区块外”；
4. 在 CAD 输入 `REINIT` 生效。

## 恢复某次备份

`backups/alias-panel-<时间戳>/` 下同时存有保存前的 `aliases.csv` 和 `ZWCAD.pgp`。恢复时关闭面板，把对应备份复制回原位置即可；PGP 目标路径见面板右上角显示。

## 保存失败的提示

- **未做任何修改**：PGP 与主表都保持原样，状态栏提示“保存未完成，未做任何修改”。
- **PGP 已写入但主表失败**：自动用备份把 PGP 恢复，状态栏提示“PGP 已用备份恢复”，并显示备份目录。
- **PGP 恢复也失败**：状态栏明确提示“PGP 与主表可能不一致，请按提示手动恢复”，弹窗给出备份路径和两个错误原因。

## 独立静态检查

```
python tools/check_alias_panel_static.py
```

已接入 `tools/check_all_static.py`，随全仓检查一起运行。单元测试位于 `tests/test_alias_panel.py`（解析/写回/校验）与 `tests/test_alias_panel_gui.py`（隐藏窗口下的编辑、删除、native 标记），测试**不会**触碰真实 `%AppData%` PGP，全部使用 `tools/fixtures/` 下的副本。
