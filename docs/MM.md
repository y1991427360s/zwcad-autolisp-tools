# MM 正交动态移动

重新加载当前项目的 `AA整合版本.lsp` 后输入 `MM`。

1. 选择需要移动的对象并回车，或预选后输入 MM。
2. 指定移动基点，保留原对象捕捉。
3. 鼠标朝水平或竖直方向移动，实时预览整批对象的位置。第二点和原生 MOVE 一样可用：
   - **输入距离**：鼠标指向方向后直接键入数值回车；
   - **对象捕捉 / 对象捕捉追踪**：沿用用户当前设置，悬停捕捉点后沿水平/竖直方向移动可得到对齐点；
   - **直接点击偏斜的捕捉点**：原生捕捉会覆盖正交，点击后命令自动反向补偿偏斜分量，只保留主方向（X、Y 中绝对值较大者），即移动到与该点水平/竖直对齐的位置。
   Esc 取消。

实现：第二点交给原生 MOVE 动态拖动（DRAGMODE=2、正交开、栅格捕捉关、网格角度归零），不再关闭对象捕捉和自动追踪。完成后由图元点位变化（或 LASTPOINT）得到实际位移，偏斜时追加一次精确的反向 MOVE 补偿，另一分量与 Z 清零。第二点直接回车（原生会以基点坐标为位移）会被撤回并提示。

结束、取消及报错均恢复正交、对象捕捉、跟踪、栅格捕捉、网格角度、拖动显示、命令回显七项设置。一次 U 可整体撤销本次移动（含自动补偿）。方向以当前 UCS 为准，显式斜向坐标同样会被投影为主方向。原 M、SS、SW、LL 不改。

仅更新中望 ZWCAD 2026 版，AutoCAD 版待用户要求同步。已做整文件解析与离线回归（`tests/test_ss_mm_ortho_osnap.py`），未连接、加载或操作 CAD，实际效果待用户重载验收。

极轴追踪：命令内部临时打开正交，CAD 会因正交与极轴互斥而清掉极轴（AUTOSNAP 位 8）。结束、取消或报错时由 `aa:ortho-restore-vars` 按原状态排序还原：原正交关闭则先关正交再恢复极轴，原正交开启则先恢复 AUTOSNAP 再开正交，并做两遍确保两项都回到原值。

Ctrl+Z 撤销：正交开关会写入撤销记录，撤销时 CAD 按逆序回放，中途会把正交重新打开一次，从而清掉极轴。现在命令在开正交前先显式关闭极轴（AUTOSNAP 位 8），撤销回放顺序变为“关极轴 → 开正交 → 关正交 → 恢复极轴”，Ctrl+Z 后极轴保持命令前的状态。
