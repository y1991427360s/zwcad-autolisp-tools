# T：统一文字样式并保持可见位置

T 将所选 TEXT、MTEXT 和 ATTDEF（属性定义）设为 HZ 样式、字高 3、宽度系数 0.7，多行文字先炸开为单行文字。整个命令保持一个撤销组。

ATTDEF 原位修改，保留属性标记、提示、默认值和属性标志，不炸开或转成普通文字。其垂直对齐读取 DXF 74（TEXT 使用 73）；DXF 73 的属性字段长度不参与定位。QW3 报告类型为 ATTDEF 的独立对象可直接框选后执行 T。此修改不遍历图块内的 ATTRIB，也不自动同步已有图块引用。

普通左基线文字保留插入点。带对齐的文字在修改前缓存实际可见范围，修改后刷新并读取新范围，再用 WCS 位移补偿；不直接相信可能过期的 DXF 11 对齐点。水平文字保留对应左/中/右及下/中/上范围锚点；旋转文字和非默认法向文字保留范围中心。字体和尺寸改变后，文字范围的大小会随之改变。

用户提供的“数量”样例中，原可见底边 Y=8365.0112，而对齐点 Y=8335.3007。旧 T 更新后可见底边落到 Y=8335.3007。修复逻辑对此补偿 Y=29.7105，保持原可见底边和水平中心。离线回归直接解析并执行范围锚点纯函数，使用该样例验证补偿计算。

无法取得修改前范围时跳过该对齐文字；修改后范围或位移失败时尝试恢复原实体数据并提示。离线检查不能证明 CAD 几何刷新和 COM 移动的实际结果。

已被旧 T 移走的文字需先撤销那次 T 或恢复原位置。重新加载根目录 AA整合版本.lsp 后再执行 T；修复不会推测已移走对象的历史位置。

离线检查：`python tools/check_t_static.py`；全仓检查：`python scripts/check_project.py`。本次未连接或操作 CAD。
