# AAE 快速属性编辑（双击属性块弹出自定义对话框）

本文档记录如何通过中望 CAD（ZWCAD）的 **CUI（自定义用户界面）** 将对象的“双击动作”绑定为自定义命令 `AAE`，实现双击属性块时直接弹出专属的轻量属性编辑对话框。

---

## 一、双击动作的设置方法（CUI 界面）

通过 CAD 的 CUI 配置，将默认的 `EATTEDIT`（增强属性编辑器）替换为 `AAE`：

1. **打开自定义界面**：
   - 在 CAD 命令行输入 `CUI` 并按回车，打开“自定义用户界面”对话框。
2. **定位双击动作**：
   - 在左上角“所有自定义文件”树状列表中，展开 **【双击动作】(Double Click Actions)**。
   - 找到并展开 **【属性】(Attribute)** 节点（通常针对属性文字编辑；也可按需设置【块】节点）。
3. **绑定自定义命令**：
   - 在左下角的“命令列表”中，可新建一个命令或直接修改原有双击动作：
     - **名称**：`快速属性编辑`（或任意易读名称）
     - **宏 (Macro)**：
       ```text
       ^C^CAAE
       ```
       > **注**：`^C^C` 代表连续触发两次 `Esc`，取消当前可能正在执行的其他命令，确保顺利执行 `AAE`。
   - 将该命令拖拽到“双击动作”树状列表中的【属性】节点下，替换原有的 `EATTEDIT`。
4. **保存生效**：
   - 点击对话框右下角的 **【应用】**，然后点击 **【确定】**。
   - 在图纸中双击块内的属性文字，CAD 就会自动执行 `AAE` 并弹出自定义属性编辑窗口。

---

## 二、弹出编辑框的文件位置与组成

自定义弹窗由两个核心文件协作实现：

### 1. 界面外观定义文件：`AAE.dcl`
- **文件路径**：工作区根目录 `AAE.dcl`
- **功能**：基于 DCL 语法定义对话框外观结构与控件布局。
- **包含元素**：
  - 对话框标题：`Attribute Editor`
  - 第一行输入框：`Line 1:`（Key: `line1`，`edit_width = 48`，支持回车确认 `allow_accept = true`）
  - 第二行输入框：`Line 2:`（Key: `line2`，`edit_width = 48`，支持回车确认 `allow_accept = true`）
  - 底部操作按钮：`OK`（默认聚焦）与 `Cancel`

### 2. 逻辑控制程序：`AA整合版本.lsp` 中的 `c:AAE`
- **文件路径**：工作区根目录 `AA整合版本.lsp`（函数 `(defun c:AAE ...)`，约 6162 行）
- **功能与处理流程**：
  1. **实体拾取与解析**：通过 `nentselp` 拾取双击点位的实体，校验图元类型是否为属性文字 `ATTRIB`。
  2. **文本清洗与拆分**：
     - 调用 `aae:clean-mtext-format` 清理多行格式码。
     - 调用 `aae:split-lines` 将原属性文本解析拆分为 `line1` 与 `line2`（按换行符拆分）。
  3. **定位与加载 DCL**：
     - 调用 `aae:locate-dcl`，按优先级搜索 `AAE.dcl`（支持当前目录、LISP 加载目录及 `*ztf-project-dir*`）。
     - 调用 `new_dialog` 载入 `aae_main`。
  4. **交互与保存**：
     - 填入原文字并激活焦点，用户修改后按回车或点击 `OK`；
     - 将修改后的内容组装，通过 `entmod`（更新 DXF 1 组码）写回属性图元，并调用 `entupd` 实时刷新图纸显示。
  5. **撤销支持**：包裹在 `aa:cmd-begin` / `aa:cmd-end` 中，一次 `U` 即可整组撤销修改。

## 三、常见问题与排查

1. **双击仍弹出原版增强属性编辑器？**
   - 检查系统变量 `DBLCLKEDIT` 是否开启（需设为 `1`）。
   - 打开 `CUI` 检查【双击动作】下的【属性】宏是否正确设置为 `^C^CAAE`。
2. **提示“找不到 AAE.dcl”？**
   - 确认 `AAE.dcl` 与 `AA整合版本.lsp` 存放在同一目录下，或已将所在目录加入 CAD 的“支持文件搜索路径”（Support File Search Path）。

## 四、如何恢复原样（改回 CAD 默认的双击动作）

如果需要恢复为 CAD 默认的双击弹出“增强属性编辑器 (EATTEDIT)”，操作步骤如下：

1. **打开自定义界面**：
   - 在 CAD 命令行输入 `CUI`，按回车。
2. **定位到属性的双击动作**：
   - 在左上角“所有自定义文件”列表中，展开 **【双击动作】** $\to$ **【属性】**（`Attribute`）。
3. **恢复为原生命令（两种方法任选其一）**：
   - **方法 A（直接改宏，最快）**：
     点击【属性】节点下的动作，在右侧属性面板中，将 **【宏】(Macro)** 的内容从 `^C^CAAE` 改回原生宏：
     ```text
     $M=$(if,$(and,$(>,$(getvar,blockeditlock),0)),^C^C_properties,^C^C_eattedit)
     ```
     *（或者直接填简版宏：`^C^C_eattedit`）*
   - **方法 B（拖拽默认命令）**：
     在左下角的“命令列表”搜索框中输入 `增强属性编辑器`（或英文 `Enhanced Attribute Editor` / `EATTEDIT`），搜出原生命令后，直接按住鼠标左键**拖拽**到【双击动作】下的【属性】节点，覆盖掉原有的自定义动作。
4. **保存生效**：
   - 点击右下角的 **【应用】**，然后点击 **【确定】**。
   - 此时在图纸中再次双击属性文字，就会恢复弹出 CAD 原生的“增强属性编辑器”。
