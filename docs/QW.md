# QW / QW2 / QW3：提取文字与对象信息

QW、QW2、QW3 都只读取选中对象，不修改图形；结果通过 `zi:to-clip` 写入 Windows 剪贴板。

- `QW`：提取所选 TEXT、MTEXT 的文字，同一行用顿号连接，行与行之间也用顿号连接。文字按 y 从上到下、行内按 x 从左到右排序，容差取字高的一半。
- `QW2`：每项一行 `x,y 文字`，坐标保留 2 位小数。
- `QW3`：导出类型、句柄、图层、颜色、线型、范围、文字内容及 MTEXT 原始内容等结构化信息。

## 多行文字（MTEXT）内容解析

MTEXT 的 DXF 内容（组码 1，超长内容配合组码 3）是带格式码的原始串，例如：

```
\pi23.89632;{\Fgbenor,gbcbig|c134;\T1.1;小电阻接地成套装置}
```

QW、QW2 通过 `aa:ysdl-get-plain-text` → `aa:ysdl-strip-mtext-format` 去掉格式码后取纯文字；AAE 属性编辑使用同类的 `aae:clean-mtext-format`。两者处理规则一致：

| 格式码 | 处理 |
|---|---|
| `\P` | 换行，转成一个空格 |
| `\p...;`（段落缩进/对齐，如 `\pi23.89632;`、`\pxi-2,l0,t0;`、`\pxqc;`） | 整段丢弃到分号 |
| `\~` | 不间断空格，转成一个空格 |
| `\F` `\f` `\H` `\W` `\Q` `\T` `\A` `\C` `\c`（带 `;` 参数） | 丢弃到分号 |
| `\L` `\l` `\O` `\o` `\K` `\k` `\X` | 开关类，直接丢弃 |
| `\S上^下;` `\S上/下;` `\S上#下;` | 取为 `上/下` |
| `\\` `\{` `\}` | 还原成 `\` `{` `}` |
| `{` `}` | 分组符号，丢弃 |

`\p` 是小写段落格式码，早期实现把它和 `\P`（换行）当成同一个分支，只跳过两个字符并把 `;` 之前的内容当成正文，导致 QW 复制出来是 ` i23.89632;小电阻接地成套装置`。现已按上表分开处理。

## 已知限制

- `\U+XXXX`、`\M+...` 这类转义字符不解析，会按字面输出；常规 DWG 中中文通常直接以字符形式保存，不受影响。
- 域代码（`%<\AcVar ...>%`）原样保留。
- `\P` 在 QW/QW2 结果中变成空格而不是顿号，跨段落的文字仍是一行。
- QW3 输出的是原始串 `MTEXT原始=`，不做任何解码，用于核对。

## 修改与检查

改动这两个解析函数会影响所有取纯文字的入口（QW、QW2、AAE、YSDL 等），需要一起回归。离线检查：

```powershell
python tests/test_mtext_strip.py     # 直接执行真实 LISP AST 的解析回归
python tools/check_all_static.py
```
