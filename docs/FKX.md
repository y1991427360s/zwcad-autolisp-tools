# FKX：单击图框内部选择正文对象

重新加载根目录 `AA整合版本.lsp`，输入 `FKX`，然后在图框正文区域的空白处点一下。命令查找包含该点、沿当前 UCS 的最小闭合矩形，选中正文对象，并排除图框边线、压边/跨框对象和右下角标题栏。

## 默认操作

1. 先让整个目标图框完整显示在屏幕内，在图纸平面视图使用。
2. 输入 `FKX`，在正文空白处点一下。不要点入小设备框、标题栏单元格或图框边线上。
3. 结果保持选中，可继续复制、移动或处理文字。需要 `PICKFIRST=1` 才能让后续命令直接使用预选；若原值为 0，请自行设置为 1 后重跑 `FKX`。命令不更改该设置。

内外框重叠时选择包含点击点的最小矩形，几何相同的重复框会去重。自动识别只支持独立的闭合直边 `LWPOLYLINE/POLYLINE`，矩形须沿当前 UCS；不钻入块参照，也不自动拼接散直线。原生 `_C` 选择依赖当前视图，屏幕外、隐藏图层或块内的边框不能保证找到。

## 标题栏排除

用户提供的 271 个对象均属于右下角标题栏，含表格线、图名、图号、签字栏和厂商标识。程序不按对象句柄或图层硬编码，而是定位内框右下角长水平线，并同时检查“图样名称/图名/DWG NAME”和“图样代号/图号/DWG NO.”两组不同字段。

候选上边线右端须与框右边对齐，宽度为框宽的 20%～85%，高度不超过框高的 35%。选择通过包围盒判定：对象必须完全位于图框内部，且包围盒不能接触或穿过标题栏区域。标题栏的重复文字、重复线条和跨入标题栏的对象均排除。极贴近框边的对象（短边长度的 `1e-8` 或 `1e-6` 单位以内，取较大值）也排除。

这些识别条件针对当前样式，不能保证覆盖所有模板。没有可靠识别结果时，会要求指定标题栏的两个对角点；按回车或 Esc 取消，不生成选择集。点击点位于已识别标题栏内时会提示重试。

## 手动操作

在“点取方框内空白处”提示处按回车，即可点选闭合矩形边框；再次按回车可指定所需范围的两个对角点。这适用于散直线构成的图框或自动识别失败时。手动方式同样尝试识别标题栏，失败时要求手动指定排除范围，不静默保留标题栏。

## 实现与离线验证

主命令和 `fkx:` 辅助函数内嵌于整合文件，不增加启动加载项。闭合矩形识别复用 FDX 的检查；每个候选对象包围盒只读取一次并缓存，临时 COM 对象及时释放。通过 WCS 包围盒的八角点转换到 UCS 后保守包络，因此旋转文字/图元靠近边界时可能比实际轮廓更严格地跳过。命令不修改、删除或隐藏图元，不更改 UCS、视图或系统变量。

`python tools/check_fkx_static.py` 实际解释执行新 LISP 辅助函数和点选模式命令，用 CAD 边界调用的离线替身检查：271 个标题栏对象全部排除，正文保留，嵌套框、边界、跨标题栏、相邻框、缺失字段、坐标平移、误点标题栏和 COM 释放路径。测试数据保留几何和识别字段，省略项目名称等无关文字。

该专项检查已纳入 `python tools/check_all_static.py` 和 `python scripts/check_project.py`。本次未在 ZWCAD 中加载或进行实机验证，离线结果不能代替 CAD 验收。
