# FKX：选择方框内部对象

重新加载根目录 `AA整合版本.lsp` 后，输入 `FKX`。

1. 先缩放视图，让目标方框完整显示在屏幕中。
2. 点选闭合矩形多段线的边框。仅支持沿当前 UCS 的直边矩形；内框和外框按实际点选对象区分。
3. 如果边框由直线拼成、重叠对象难以点选，或不想包含标题栏，在边框提示处按回车，再指定需要范围的两个对角点。
4. 命令将完全位于框内的对象保留为选中状态，可以继续复制、移动或运行文字处理命令。`PICKFIRST=0` 时，后续命令输入 `P` 使用上一选择集；也可以自行设 `PICKFIRST=1` 启用预选。

选择所有对象类型，不按图层或颜色过滤。边框、压边和跨框对象排除；内容不会删除、移动或隐藏。图框内的标题栏文字等对象也会选中。块参照按整体选择，不提取块内部的独立实体。重叠的内部对象仍各自保留，不自动去重。

实现复用 `fdx:poly-rect` 的闭合、四角和无弧段检查；以短边长度的 `1e-8` 为内缩距离，再执行原生窗口选择 `_W`，排除相同位置的重复边框。极贴近边界、位于这条微小内缩带内的对象也会排除。两角点方式按当前 UCS 生成矩形。

原生窗口选择依赖当前视图：请完整显示方框，并在图纸平面视图使用。旋转 UCS 后，若闭合矩形不沿 UCS，可恢复与方框平行的 UCS 再选。命令不更改视图、UCS 或预选设置。

本次仅执行离线解析、命令结构和全仓静态检查，未在 ZWCAD 中加载或实测。
