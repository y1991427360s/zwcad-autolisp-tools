# TBHB — 多表上下拼接

## 使用方法

1. 框选需要合并的完整表格，包含全部边线和文字；也可先输入 `TBHB` 再框选。
2. 输入 `TBHB`。
3. 点选长表的左上角，生成拼接副本。原表保留；一次 `U` 撤销本次全部输出。

排序严格依据 WCS 中各表上沿的 Y 坐标，从高到低；上沿高度相同时按左边 X 坐标从小到大。不读取标题参与排序。因此示例图的顺序是 **11D → 13D → 12D → 14D**，即实际上下位置顺序。

## 合并效果

- 各表左边对齐，下一表的顶边紧接上一表底边，没有额外空隙。
- 保留每段的标题、列顺序、序号、行高和文字/边线属性；只复制平移，不重排单元格。
- 示例中 11D/13D 的“编号、L1/N1、序号”以及 12D/14D 的“编号、序号、L1/N1”保持原样。
- 接缝和表内近重合的重复直线（端点差不超过 0.01 图形单位）只复制一次。文字全部保留，不按内容去重。
- 复制/移动出错或取消时，清理本次已经生成的副本，并关闭撤销组，不修改源表。

## 当前支持范围

支持由 `LINE` 与 `TEXT/MTEXT` 组成、位于 WCS XY 平面的同宽矩形表格。识别需具有完整直线外框，支持由多段相接或重叠直线组成的左右边框、分段横线和合并单元格；识别时合并共线线段，复制时保留原图结构；边线允许不超过 0.01 图形单位且坡度不超过 0.0001 的微小偏差。文字可与边线位于不同图层。

请选择完整表格，不包含表外文字或其他对象。宽度不一致、表格相互重叠、锁定图层、缺失外框，或选择中出现块、多段线、CAD 原生 TABLE 等对象时，命令停止，不生成副本。无需切换 UCS；输出点转换为 WCS 后处理。

此命令复制生成相接的线和文字长表，不转换为原生 TABLE 或块。
