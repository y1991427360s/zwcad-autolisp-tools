# HBBG — 多表上下拼接

## 使用方法

1. 框选需要合并的完整表格，包含全部边线和文字；也可先输入 `HBBG` 再框选。
2. 输入 `HBBG`。
3. 点选长表的左上角，生成拼接副本。原表保留；一次 `U` 撤销本次全部输出。

排序严格依据 WCS 中各表上沿的 Y 坐标，从高到低；上沿高度相同时按左边 X 坐标从小到大。不读取标题参与排序。因此示例图的顺序是 **11D → 13D → 12D → 14D**，即实际上下位置顺序。

## 合并效果

- 各表左边对齐，下一表的顶边紧接上一表底边，没有额外空隙。
- 保留每段的标题、列顺序、序号、行高和文字/边线属性；只复制平移，不重排单元格。
- 示例中 11D/13D 的“编号、L1/N1、序号”以及 12D/14D 的“编号、序号、L1/N1”保持原样。
- 接缝和表内近重合的重复直线（端点差不超过 0.01 图形单位）只复制一次。文字全部保留，不按内容去重。
- 复制/移动出错或取消时，清理本次已经生成的副本，并关闭撤销组，不修改源表。

## 当前支持范围

支持以 `LINE` 构成外框的同宽矩形表格。表内对象不按类型限制：文字、块、多段线、圆、圆弧、填充、尺寸、样条曲线等，只要完整范围位于表内且支持 COM 复制/移动，均随所属表格原样复制平移，保留属性。表内斜线与带 Z 坐标的内容也保留；归属依据 WCS XY 投影范围。

外框识别使用 WCS XY 平面上近水平、近竖直的 LINE，支持多段相接/重叠边框、分段横线及合并单元格。识别时合并共线线段，复制时保留原图结构；边线允许不超过 0.01 图形单位且坡度不超过 0.0001 的偏差。其他对象仅作为表内内容，不参与外框识别。

请选择完整表格，不包含表外对象。宽度不一致、表格相互重叠、锁定图层、缺失外框、对象不能取得范围或不支持复制/移动时，命令停止，不静默丢弃内容。对象处理异常会提示类型与句柄。无需切换 UCS；输出点转换为 WCS 后处理。

此命令复制生成相接的线和文字长表，不转换为原生 TABLE 或块。
