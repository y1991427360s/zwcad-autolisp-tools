# YSDL 命令使用说明

## 命令概述

`YSDL` 是用于提取图纸电缆文字清册并导出到桌面 CSV 文件的 AutoLISP 命令。

2026 升级版本新增**多分类空间识别**能力：
- **分类框识别**：自动识别长宽为 5000（±200 容差，即 4800~5200）的闭合矩形多段线（LWPOLYLINE）；
- **分类名称提取**：在各分类框内检索字高为 500（±30 容差，即 470~530）的单行/多行文字作为【分类名称】（如“公用部分”、“110kV部分”）；
- **框间几何排序**：按图纸自上而下、从左到右对各分类框进行排序；
- **前缀列扩展**：导出结果前三列新增【分类】、【序号】、【安装单位名称】；
- **聚类序号编排**：同一分类内按【安装单位（即起点设备名称）】聚类编号，相同起点的连续电缆行分配相同序号，切换分类后序号重置为 1 开始；
- **平滑兼容回退**：未检测到 5000×5000 矩形框时，自动平滑回退为传统无分类电缆导出格式。

## 导出 CSV 列结构

### 1. 分类框模式（检测到 5000×5000 矩形框时）
| 列号 | 字段名称 | 说明 |
| :--- | :--- | :--- |
| 第 1 列 | 分类 | 当前分类框内字高 500 的标题文本（如“公用部分”） |
| 第 2 列 | 序号 | 分类内部聚类序号（相同起点连续行序号相同，换分类重置为 1） |
| 第 3 列 | 安装单位名称 | 取当前电缆的起点设备名称（与起点文字一致） |
| 第 4 列 | 电缆编号 | 原第 2 列文字（如 `DS-01`） |
| 第 5 列 | 所用芯数 | 原第 5 列文字（如 `2`） |
| 第 6 列 | 电缆型号及截面 | 原第 4 列文字（如 `通讯线`） |
| 第 7 列 | 起点 | 原第 1 列文字（如 `同步时钟柜`） |
| 第 8 列 | 终点 | 原第 3 列文字，自动清洗去除“至”字前缀（如 `远动通信柜`） |
| 第 9+ 列 | 原后续列 | 如存在后续列（如 `B+`、`B-`、长度等），按原样追加 |

### 2. 传统回退模式（仅选择纯文字时）
| 列号 | 字段名称 | 说明 |
| :--- | :--- | :--- |
| 第 1 列 | 电缆编号 | 原第 2 列文字 |
| 第 2 列 | 所用芯数 | 原第 5 列文字 |
| 第 3 列 | 电缆型号及截面 | 原第 4 列文字 |
| 第 4 列 | 起点 | 原第 1 列文字 |
| 第 5 列 | 终点 | 原第 3 列文字（去除“至”字前缀） |
| 第 6+ 列 | 原后续列 | 后续列按原样追加 |

## 核心规则与工作流程

1. **两段式稳定排序与分行**：
   - 提取框内电缆文字坐标，按 Y 坐标降序（从上到下）稳定排序；
   - 依据 `*YSDL_RowFuzz*` 容差线性单趟分行，并在行内按 X 坐标升序（从左到右）排序。

2. **文本清洗与公式转义**：
   - 终点列及所有单元格文本清洗去除“至”字前缀并修剪首尾空白；
   - 包含 `=`、`+`、`-`、`@` 等 Excel 公式符号的前缀安全转义（前置制表符）并加双引号防注入。

3. **变色与撤销**：
   - 导出完成后，所有被提取的文字 ACI 颜色自动改为 `*YSDL_TextColor*`（默认为 2 黄色）；
   - 整命令处于完整 Undo 组内，在 CAD 中输入 `U` 可一次性撤销全部改色与状态修改。
