# ZDDL / ZDDL2 端子排电缆绘图

适用：当前项目的 ZWCAD 2026。重新加载当前项目 AA整合版本.lsp 后生效。

## ZDDL 对齐修正

继续选择已有端子排及接线方格。向上电缆的原理号以外侧格顶边内缩 2mm 为上端对齐点；向下电缆以外侧格底边内缩 2mm 为下端对齐点。旋转 90 度的 TEXT 分别采用右中 / 左中对齐。长编号仍按真实格长收缩，已有文字保留。

2026-10-17 修正：同批电缆的横向干线统一延伸到最长去向/规格标注的右端，三角标仍在同一列。短接横线的端点位于端子中心，不再当作文字格边框；真实横框须在两端与竖框相接。编号带相距 1mm 的双横框合并为边界，避免将窄缝当作文字格；合并容差随列宽缩放且不超过 1.5mm。下侧空格恢复正常原理号回写，仍按格长收缩并保留已有文字。

## ZDDL2 操作

1. 输入 ZDDL2。
2. 选择端子名和端子号文字，空格确认。
3. 选择电缆接线文字，空格确认。也可包含原理图接线方格边框，沿用 ZDDL 的方格识别。
4. 选择向上 Shang 或向下 Xia，默认向上。
5. 指定生成图左下基点，在当前图中创建可编辑的 LINE、TEXT 和闭合三角形。一次 U 撤销本批。

端子输入沿用网页格式。原理图散字采用 DX1 的规则：青色排名自动标记为“端子名”，其他选中文字作为端子号，按实际坐标分列/分排。也支持普通文字行“JD、1、2、4、5”。MTEXT 格式代码会去除，段落换行保留。原理图排名不为青色时，可在名称后明确加上“ 端子名”。

电缆输入例如“JD:1、L1、JD:4、N1、相邻屏柜”。半角、全角冒号及网页已有的无冒号引用均沿用核心解析规则。接线方格使用原有 ZDDL 分组逻辑。

只绘制选中的端子排。电缆接到未选端子时跳过该接点；去向和原电缆编号保留，不会因为跳过一条记录而合并前后电缆。部分接点匹配的电缆只画匹配部分，整根无匹配接点的电缆不画；不会自动补画未选端子。即使没有匹配电缆，也可以生成所选端子排。

## 本机实现

- CAD 入口和图元生成内嵌于主整合文件，旧独立 ZDDL 文件仅作为兼容加载入口，防止同名函数覆盖。
- tools/zddl2_engine.py 为 D:/Syncthing/Oracle-Sync/2ci/vendor/modules/terminal/duanzi_dxf_tool.py 的本地快照，网页项目本身未改动。本机调用同一解析/布局/绘图算法，不依赖网页、服务器或浏览器。
- tools/zddl2_bridge.py 仅在本机生成临时绘图数据。CAD 用 read 读取数据并通过 entmake 平移到指定 WCS 基点，不执行数据文件中的代码。
- 2026-10-17 起改为纯 AutoLISP 实现，`c:ZDDL2` 不再调用 Python 或 ezdxf；解析、布局与图元生成全部在 `AA整合版本.lsp` 内完成。`tools/zddl2_engine.py` 与 `tools/zddl2_bridge.py` 保留为 Python 参考实现，供 `tests/test_zddl2.py` 对照使用，不再被 CAD 调用。离线对照 24 组样例通过（含 3 组中文专项）；中望 CAD 实机尚未验证。
- 端子格宽 5mm、端子号带高 5mm、上下接线区各高 35mm，电缆首距 10mm、级距 5mm，沿用网页核心；同端子多接线以 1.5mm 间距错开。
- 目标绘图图层已锁定时停止，不自动解锁。已有 HZ 样式复用；不存在时创建网页默认的 txt.shx / hztxt.shx 样式。实际字体显示取决于 CAD 可用字体。
- 默认在 WCS XY 方向出图，插入点由当前 UCS 转换成 WCS；不旋转整幅图以追随斜 UCS。
