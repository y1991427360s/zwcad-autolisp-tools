# HDDZ 核对原理图与端子图的端子—原理号

适用：中望 CAD 2026，`AA整合版本.lsp`（2026-11-04 新增，未经 CAD 实机验证）。重新加载整合文件后生效。

## 用途

画好端子排图后，核对端子图上每个端子接的原理号是否和原理图一致：原理号写错、漏接、端子图多出或少了端子都会列出来。命令只读，不改任何原文字、颜色和位置。

## 操作

1. 输入 `HDDZ`。
2. **第一次选择**：选从原理图里剔出来的端子和原理号文字，空格确认。
   - 白色文字是端子，写成 `端子名:端子号`，如 `YD:4`、`1-2ID:5`（全角冒号、空格都可以）。
   - 青色文字是原理号，如 `2AW-901`。含汉字的柜名不参与。
   - 端子和原理号在同一行左右排列时，原理号归左右两侧间隙更近的端子（一样近归左边）；一行写几组（`YD:4 2AW-901    YD:11 2AW-913`）也行。
   - 上下排列（端子一行、原理号下一行）时，原理号归上方最近的端子。
3. **第二次选择**：选端子图，可直接框选整块端子排（框线、电缆线等非文字会自动排除），空格确认。
   - 白色纯数字或数字+a（`7a`）是端子号，白色其他文字（`YD`、`IB1D`、`1-2ID`）是端子名，青色是原理号。含汉字的说明（如 `#1主变高压侧`）、电缆的“至…”“未编号”“未填写”、截面、柜名大字不会当成端子名。
   - 自动判断方向：端子号横着排一行（`ZDDLH`）时原理号和端子号**上下对应**（X 对齐），端子名在同一高度的左侧；端子号竖着排一列（`ZDDLS`）时原理号和端子号**左右对应**（Y 对齐），端子名在同一列的上方。
   - 一个端子上下都接线（两个原理号）也能识别。
4. 命令行一行汇总，明细在“CAD 结果”卡片（点条目缩放到该端子）；问题端子同时被选中。

## 核对规则

- 两边按 `端子名:端子号` 对应，比较各自的原理号集合（忽略空格、大小写、先后和重复）。
- 端子图没框到端子名，或原理图写的端子没有冒号时，按端子号对应，前提是另一边同号的端子只有一个；同号有几块端子排就没法区分，会报“端子图缺端子”，请把端子名一起框进去。

| 卡片类别 | 含义 | 图上标记 |
|---|---|---|
| 原理号不一致 | 两边都有原理号但不同 | 原理图行尾红字 `端子图：…`；端子图红圈 |
| 端子图未接线 | 端子图有这个端子但没有原理号 | 红字 `端子图未接线`；红圈 |
| 原理图没标原理号 | 原理图端子没写原理号、端子图有 | 红字；红圈 |
| 端子图缺端子 | 原理图有、端子图里没找到这个端子 | 红字 `端子图没有这个端子` |
| 原理图没有（提醒） | 端子图有原理号、第一次选择里没有这个端子（只选了部分原理图时会很多） | 红圈 |
| 原理号未对应端子（提醒） | 原理号附近找不到对齐的端子号 | 原理图红字 / 端子图红圈 |
| 端子重复（提醒） | 同一个端子在一边出现多次（如框进了两块同名端子排），原理号合在一起比对 | 无 |

两边都没有原理号的端子（备用端子）算一致，端子图上多出的备用端子不报。

## 标记与撤销

- 红字、红圈在 `HDDZ_MARK` 图层（红色）。改图后再跑 `HDDZ`，会先删掉这两次选择范围内上次留下的标记再重新标。
- 不需要时关闭或删除 `HDDZ_MARK` 图层；一次 `U` 撤销本次的全部标记。

## 识别细节

- 端子图：同一行相邻端子号相距 0.1 到 max(12, 4 倍字高) 的认作横排，同一列的认作竖排；原理号与端子号在对齐方向的偏差不超过 0.45 倍端子间距（ZDDL 格宽 5 → 2.25），另一方向不超过 max(60, 20 倍字高)，取最近的端子号。距离都随字高放大，图纸比例不同也能认。
- 端子名：横排取同一高度（± max(6, 2 倍字高)）左侧最近的端子名，竖排取同一列上方最近的端子名；同一排多块端子排（如 `IB1D`、`IB2D` 各 1~8）各自取自己的名字。
- 原理图：同一行指中心高差不超过 1.5 与 0.6 倍字高中较大者；上下排列时原理号到端子不超过 15 倍字高。
