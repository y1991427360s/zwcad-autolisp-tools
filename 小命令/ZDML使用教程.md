# ZDML 使用教程

`ZDML` 用来从图框块里提取 `图号` 和 `图名`，并自动生成目录文字。

## 1. 加载命令

在 CAD 中用 `APPLOAD` 加载：

```text
E:\366256\ZW-auto_lisp\小命令\自动目录ZDML.lsp
```

加载成功后，命令行会提示可以输入 `ZDML`。

## 2. 生成目录

1. 命令行输入：

   ```text
   ZDML
   ```

2. 根据提示选择需要统计的图框块。

3. 选择完成后，指定目录表左上角位置。

4. 程序会自动生成三列目录：

   ```text
   序号    图号    图名
   ```

## 3. 图框要求

图框必须是带增强属性的块，并且属性标记里要有：

```text
图号
图名
```

没有这两个属性的块会被跳过。

## 4. 查看图框属性

如果生成不了目录，先用调试命令检查图框属性：

```text
ZDMLDEBUG
```

然后点选一个图框块，命令行会显示该块所有增强属性。

确认里面是否有 `图号` 和 `图名`。

## 5. 注意事项

- 旧目录不会自动删除，需要手动删。
- 特殊或异常图框会被自动跳过。
- 目录只生成文字，不生成表格线。
- 修改 `.lsp` 文件后，需要重新加载才能生效。
